# SM103 / B300 — Datacenter Blackwell Variant

SM103 is the datacenter Blackwell architecture variant shipped in B300 and GB300 products. Within this wiki's alias map, `B300` and `GB300` resolve to `sm103`. Kernel-facing behavior follows the SM100 programming model — the tcgen05 MMA, TMEM, and block-scaled FP paths documented on the related pages all list `sm103`/`sm103a` among their target architectures — so this page records only what the retained upstream sources show as SM103-specific activity, not a claimed hardware delta beyond those sources.

## Ecosystem support retained in the corpus

- **CUTLASS CuTe DSL** added an SM103 grouped block-scaled GEMM kernel with tests ([pr-cutlass-3124](../../sources/prs/cutlass/PR-3124.md)).
- **FlashInfer** landed initial support spanning the variant targets SM103, SM110, SM120, and SM121 ([pr-flashinfer-1608](../../sources/prs/flashinfer/PR-1608.md)), enabled an SM103 MoE DSL backend ([pr-flashinfer-2149](../../sources/prs/flashinfer/PR-2149.md)), and ships `cake_*` kernels built for `sm_100a`/`sm_103a` together — for example faster tcgen05 and small-M programs on SM100/SM103 ([pr-flashinfer-7419](../../sources/prs/flashinfer/PR-7419.md)) and two-CTA large-N/K batch DeepGEMM builds ([pr-flashinfer-7528](../../sources/prs/flashinfer/PR-7528.md)).
- **DeepGEMM** integrated a kernel set spanning `sm90` through `sm121` including `sm103` while preserving the `nv_dev` sparse-MQA features ([pr-DeepGEMM-447](../../sources/prs/DeepGEMM/PR-447.md)).

The pattern across these sources is that projects build and tune variant-specific `sm_103a` artifacts alongside the SM100 ones rather than porting a separate kernel family.

## Selection guidance

Write kernels against the SM100 model (tcgen05 + TMEM + block-scaled FP) and treat SM103 as an additional validation and tuning target. Performance-tuned schedules are increasingly shipped per-SKU — FlashInfer regenerates separate `sm_100a` and `sm_103a` stage configurations — so do not assume a schedule tuned on one variant transfers without measurement.
