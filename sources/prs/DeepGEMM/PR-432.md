## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This update introduces new kernels, features, and performance improvements:

### New kernels
  - Sparse Indexer: hierarchical sparse indexing for V4.1, with throughput close to the Lightning Indexer.
  - Mega Gate: fuses the routing GEMM and multiple MoE routing operations into one kernel, with 30–75% speedups.
  - Mega mHC: fuses multiple Hyper-Connection operations and RMSNorm into one kernel, with 45–85% speedups.

### New features
  - Integration with [DeepJIT](https://github.com/deepseek-ai/DeepJIT), a lightweight, header-only JIT runtime.
  - More epilogue fusion options, including runtime alpha scaling and fused output casting.
  - Broader use of cuBLASLt for simpler GEMM and batched operations.

### Performance improvements
  - Faster MoE backward GEMMs, with ~20% gains.
  - Mega MoE optimizations for V4.1: ~15% faster at low latency, ~4% at high throughput.
  - Improved Lightning Indexer kernels, with a follow-up version (~30% faster) coming soon.

### Breaking changes
  - Previously, all kernels were fully deterministic and batch-invariant.
  - This release adds a `use_deterministic_algorithms()` API, which defaults to `False` so some kernels can run faster.
