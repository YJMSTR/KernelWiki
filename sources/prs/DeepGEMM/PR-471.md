# DeepGEMM 2.8.2

This update adds fused FP8 clamping and statistics, improves GEMM epilogue conversion, and expands paged Sparse Indexer layout support.

## New features

- Fused FP8 cast with optional clamping: deep_gemm.epilogue.FP8CastWithClamp converts BF16-rounded GEMM output to FP8, with optional symmetric clamping before scaling.
- Optional clamped-element counts: Pass a single-element CUDA torch.uint32 tensor as clamped_count to collect the total asynchronously. Each invocation overwrites the previous count.
- More flexible paged Sparse Indexer layouts: Paged sparse KV caches now accept page strides aligned to 128 bytes, relaxing the previous 512-byte requirement.

## Performance improvements

- Use packed FP8 conversion and a packed BF16 clamp instruction to improve fused conversion efficiency.
- Consolidate epilogue conversion paths for FP8 and BF16 outputs, including stochastic rounding.
- Improve swap-AB epilogue scheduling by preparing scaling factors for both TMEM fragments before FP8 conversion.
- Reduce clamped-element counts within each warp before updating the global counter.
