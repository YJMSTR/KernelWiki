## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
In this PR, we merged the four SM100 fp8/fp4 mqa logits kernels (paged/non-paged) into a single kernel and added flexible support for various combinations of `num_heads`, `head_dim`, and reduce precision `(float32/bfloat16)`. This yields ~2% speedup for fp4 non-paged cases, ~10% for fp4 paged varlen (due to scheduler and load balancing improvements), and ~20% when using bf16 precision for reduction.

For Mega MoE, we now support BF16 precision, which also brings significant acceleration to BF16 MoE. Additionally, we implemented a ring buffer that substantially reduces memory usage compared to the previous version.

There are also several other minor improvements.
<!-- upstream-excerpt-end -->
