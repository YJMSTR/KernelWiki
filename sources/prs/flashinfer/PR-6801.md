## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR re-exports Cake's StepFun SwiGLU fused-MoE kernels (H=4096, I=1536, E=64 experts, top-k 8) in the cake-build/1 form. The family has four data-type variants: bf16, fp8 (e4m3), mxfp8 and nvfp4. Each architecture has 111 kernels, covering routing, FC1+SwiGLU, NVFP4 requant, FC2 and finalize. This PR delivers all four families. The kernels are the same ones shipped in #6046 and are SASS-identical to them, so only the delivery form changes. The baseline is the previous Cake version of these kernels, the earlier package form from #6046. We measured whole-graph CUDA-graph replay on the same node, comparing the previous form with this PR. End-to-end time is at parity: GB300 median 1.000x (range 0.993x–1.003x) and B200 median 1.000x (range 0.993x–1.065x). The tables have one row per cell of the shape list, which has 32 cells: 4 families × tokens {8, 64, 512, 2048} × expert step limit {7, 16}. Latencies are medians in µs, and speedup is previous / this PR.
