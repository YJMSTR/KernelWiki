## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
The QSA NVFP4 sparse paged decode attention kernel (BF16 queries, NVFP4 paged KV with E4M3 block scales, top-k sparse page selection, split-KV with an LSE-gated merge) comes in two layouts (NHD and HND) and two forms. The split form is a decode kernel plus a merge kernel, and the fused form is one co-resident kernel that merges in-kernel. This PR adds the SM100 / SM103 (B200 / GB300) programs on the fifth-generation tensor cores: the split form on all hosts, plus the fused form on aarch64 hosts (GB300's Grace) for eager calls of at most four rows. The baseline is the FlashInfer reference implementation `qsa_nvfp4` built for the device because no earlier Cake version of this kernel ships for SM100 / SM103; speedup is the reference latency divided by this route's latency.

Speedup of this PR's route (`backend="cake"`) over the FlashInfer reference (`qsa_nvfp4`, host guard bypassed, built for the device) on NVIDIA GB300 (152 SMs, sm_103a), CUDA 13.4 (torch 2.14.1+cu130, torch CUDA 13.0), SM clock 2070 MHz median (120-2070) during the run; whole call (decode + merge), medians of 3 x 64 cold-L2 samples (memset flush), eager launches; 24 x 2 heads, 2051 selected tokens per row.
