## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
The DeepGEMM-derived FP8 1D1D GEMM behind `flashinfer.experimental.deepgemm_fp8_gemm.prepare_fp8_gemm_1d1d` takes FP8 e4m3 operands with per-128-block UE8M0 scales and produces BF16 output. It has two variants: the forward GEMM, which writes a fresh output, and the weight-gradient GEMM, which accumulates into the existing output. This PR delivers both variants as one self-contained package. The baseline is the previous Cake version of these kernels, meaning the same kernels as shipped before this PR through the previous loader. Speedup is previous / new, and timings are median GPU kernel time with a cold L2 over 3 interleaved groups of 128 iterations per side. It is ≈1.00 on every shape (0.972 to 1.019), so the re-packaged kernels run at the same speed.

**Forward GEMM on NVIDIA GB300 (sm_103a, compute capability 10.3), CUDA runtime 13.0, kernels JIT-compiled with CUDA 13.4 (13.4.92)**

|---|---:|---:|---:|
| M=4096 N=7168 K=4096 | 66.880 | 66.801 | 1.001 |
| M=1024 N=2048 K=1024 | 6.656 | 6.656 | 1.000 |
| M=3000 N=4000 K=1152 | 12.992 | 12.960 | 1.002 |
| M=128 N=1024 K=512 | 5.600 | 5.504 | 1.017 |
