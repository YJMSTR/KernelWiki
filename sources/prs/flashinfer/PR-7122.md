## 📌 Description

### Summary

This PR is the round-2 deslop of the Cake `cake_blackwell_softmax` family. The family is the fused softmax behind `flashinfer.sampling.softmax` on SM100 (B200, compute capability 10.0) and SM103 (GB300, compute capability 10.3). It is a normal, non-experimental part of the repository.

The sources are the dispatcher `csrc/cake_blackwell_softmax.cu`, the header `include/flashinfer/cake_blackwell_softmax.cuh` and the kernel units `csrc/cake_blackwell_softmax_{bootstrap,rowwise,warp,mr515_exp2,cached_cluster}.cu`. With the dispatcher, these are the six units of the JIT module `blackwell_softmax`. The dispatcher picks one of several routes. The "cached cluster" route launches one kernel from `csrc/cake_blackwell_softmax_cached_cluster.cu`. `select_cached_variant` picks that kernel from a table of (C, T) variants. C is the cluster size and T the tile count.

The two commits are mechanical:
- commit 1 deletes the 3 cached-cluster kernels that the host-side selection never produces;
