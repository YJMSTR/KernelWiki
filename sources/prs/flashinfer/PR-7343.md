## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`cake_nvfp4_mla_decode` (`flashinfer.mla.prepare_nvfp4_batch_decode_with_kv_cache_mla`, experimental) is the DeepSeek-V4 main-attention decode with NVFP4 queries and KV cache (E2M1 values with UE4M3 block-16 scales), one 512-wide latent row per token that serves as both K and V, 64-token pages, an optional per-head attention sink, BF16 output and FP32 LSE; its single variant runs a persistent decode program and a split-KV combine program. This PR replaces that variant's decode program with a faster build of the same kernel and leaves the combine program unchanged. Measured against the previous Cake version in `main`, the speedup is 1.012x to 1.056x on GB300 and 1.012x to 1.032x on B200, where speedup is `main` latency divided by this PR's latency, each the median of one complete call (decode, plus the combine when a request is split).
