## 📌 Description

SM120 FP16 W4A16 preparation currently clears valid NVFP4 E4M3 subnormal block scales: after multiplying by 128, it clamps every value below 2 to zero. This silently changes checkpoint weights for scales below 1/64.

Forward the activation dtype into packed-scale preparation and preserve these values for FP16, whose existing packed decoder represents them exactly. Add an exhaustive finite nonnegative E4M3 encoding regression and subnormal-scale coverage for direct/packed routes and live CUDA-graph replay.

## 🔍 Related Issues

Found while validating the native SM120 W4A16 backend as a correctness-checked comparison for low-latency MoE work.
