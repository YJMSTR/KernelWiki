## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
The kernel behind `minimax_h3_fp8_pre_attention` and `minimax_h3_nvfp4_pre_attention` has 6 variants in this module: FP8 E4M3 or NVFP4 input, each with bf16, e4m3 or nvfp4 output. This PR delivers all 6 on sm_120a. The baseline is the previous Cake version of the kernel, which is the current FlashInfer route of these two entry points.

**NVIDIA GeForce RTX 5090, sm_120a, CUDA 13.4 toolkit, PyTorch cu130, power limit 575 W.** The tables show GPU kernel time per operator call, which is the busy time of the call's kernels with launch gaps excluded. Each implementation is timed in its own back-to-back runs, interleaved with the other, with a cold L2.

| input | output | M | baseline (ms) | this PR (ms) | speedup |
|---|---|---|---|---|---|
| FP8 | bf16 | 33472 | 18.6993 | 13.6945 | 1.3655x |
| FP8 | bf16 | 38592 | 21.6638 | 16.0710 | 1.3480x |
| FP8 | bf16 | 48768 | 27.3220 | 20.3686 | 1.3414x |
| FP8 | bf16 | 58944 | 33.1731 | 24.7679 | 1.3394x |
