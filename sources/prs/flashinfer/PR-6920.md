## Summary

This PR is the round-2 deslop of the five Cake DeepGEMM-signature GEMM families tracked in #6663. The families are fp8 1D1D, native fp4, fp4 K-grouped (kgroup), mixed fp8/fp4 and fp8 batched, with 46 programs and 89 builds for SM100 and SM103. The PR has five mechanical commits and one test fix:
- The bindings include the shared host header instead of four per-family copies.
- Dead registry text is removed.
- 11 duplicate kgroup bindings fold onto 7 shared bindings that compile definitions re-point.
- 14 kgroup kernel files fold onto 4 bodies that compile definitions select.
- 133 copies of shared TMA encoder bodies move into one host header.
- The catalog sweep in `tests/experimental/test_deepgemm_common.py` checks a family's catalog against that family's own architecture table, which fixes a failure that existed on upstream main before this PR (commit 6).

Device code, routes, launch arguments, exports and module names do not change.
