## 📌 Description

Optimize sparse Blackwell MegaMoE dispatch and reduction, and add an opt-in decoding backend with N128 and N64 configurations.

Performance on **4×B300, EP4, unlocked clocks**, using synthetic DeepSeek V4 Pro shapes, **MXFP8 W8A8 with BF16 output**, and capacity 1024:

| Tokens/rank | Before PR (µs) | GenPhase N64/CGA2 (µs) | Latency reduction |
|---:|---:|---:|---:|
| 1 | 144\.8 | 107\.2 | 26\.0% |
| 4 | 403\.3 | 286\.2 | 29\.0% |
| 16 | 1034\.6 | 707\.3 | 31\.6% |
| 64 | 1506\.6 | 1047\.1 | 30\.5% |
| 256 | 1546\.6 | 1069\.0 | 30\.9% |
| 1024 | 1576\.1 | 1331\.2 | 15\.5% |
