## 📌 Description

This adds a Cake-generated MiniMax-H3 **NVFP4 (W4A4)** pre-attention implementation for
NVIDIA B200 (`sm_100a`) and B300 (`sm_103a`), candidate **2B** of #4532 (the MXFP8
candidate 2A landed in #5060). The generated programs were exported and measured against the routing
scaffold commit `610db3992f8c0087de7ec2106fd37c7ea7c29438` of this branch (the first runtime-M scaffold,
`27133c35`, amended in place: the pack stage now enumerates the destination on `grid.y`, see below).

The prepared `MiniMaxH3Nvfp4PreAttention` operation composes two generated stages with
FlashInfer's `mm_fp4` NVFP4 GEMM (CUTLASS / cuDNN backend and tactic pinned per architecture and
shape at preparation time):

`BF16 input → RMSNorm → indexed AdaLN → dynamic NVFP4 activation quantization (E2M1 + swizzled 128x4 E4M3 block scales) → NVFP4 QKV GEMM (mm_fp4) → per-head Q/K RMSNorm → D96 split-half NeoX RoPE → destination-major NVFP4 QKV pack`
