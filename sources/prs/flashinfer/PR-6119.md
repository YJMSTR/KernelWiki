## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
The `cake_fmha` balanced DCP speculative-decode attention kernel serves paged KV caches with context parallelism and speculative q_len rows per request. Cake ships it in three families, each with BF16 Q: BF16 KV cache at head_dim 128, E4M3 KV cache at head_dim 128, and E4M3 KV cache at head_dim 256. Each family ships 32-row and 64-row packed instances. This PR changes the E4M3 head_dim-128 family (`dcp_spec_bf16_fp8_balanced`). It adds program 2, a plan-free static one-wave program, to the host `program` selector. Program 0 is the device planner without the idle-CTA eight-slice fold, used at or above the grid. Program 1 is the device planner with the fold and stays the default. Program 2 applies when two conditions hold. First, the block-table width bounds every (request, KV head) tile to at least 3 chunks of 256 tokens. Second, the chunk and reduce tickets fit the grid. In that case, each CTA derives its ticket from its block index and skips the device planner. Output is bitwise identical to program 1.
