## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
The kernel behind `MiniMaxH3Nvfp4PreAttention` (`flashinfer.cake_minimax_h3`) is the MiniMax-H3 fused pre-attention with NVFP4 input. It has two stages: a norm stage (RMSNorm, AdaLN, NVFP4 quantize) and an NVFP4 QKV GEMM with a fused epilogue (Q/K RMSNorm, NeoX RoPE, destination-major pack). It has 4 variants: 2 output formats (`out_format="nvfp4"`, the default, and `out_format="e4m3"`) on 2 architectures (sm_100a and sm_103a). This PR changes the norm stage for four destinations (P = 4) on sm_103a, for both output formats. All other shapes run the same kernels as on main: P = 1, 2 and 8 on GB300, and every GB200 shape. The baseline is the previous Cake version of the kernel, which is the current FlashInfer route of this entry point. On GB300 the speedup is 1.0051x to 1.0189x with nvfp4 output and 1.0049x to 1.0221x with e4m3 output.

**NVIDIA GB300, sm_103a, CUDA 13.4 toolkit, PyTorch cu130, power limit 1400 W.** The tables show GPU kernel time per operator call, which is the busy time of the call's kernels with launch gaps excluded.
