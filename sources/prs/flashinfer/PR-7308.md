## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`flashinfer.sampling.softmax` on Blackwell (`cake_blackwell_softmax`) has one data type (FP32) and one layout (row-major `[rows, vocab]`). It can fuse a scalar or per-row temperature, and it can use PDL on sm_103a. After this PR, 14 Cake programs serve it: a warp program, a rowwise program, a bootstrap program, 7 row-caching cluster programs (1- to 16-CTA clusters x 4 or 8 tiles), 2 persistent programs (8- and 16-CTA clusters, 8 tiles) and 2 new shared-tile programs (8- and 16-CTA clusters, 4 register tiles plus up to 4 shared-memory tiles per CTA). This PR delivers the 2 shared-tile programs. Each CTA keeps half of its 8-tile chunk in shared memory, so four CTAs per SM stay resident instead of two. Compared with the previous Cake version in FlashInfer main (`a0a6460f6`, which includes #7277), the geometric-mean speedup across the 41 shapes below is 1.008x on B200 and 1.009x on GB300.
