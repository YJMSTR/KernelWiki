## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
The packed KDA chunked training forward and backward has one Cake variant: BF16 tensors with an FP32 gate, laid out as `[1, S, H, 128]`. Its saving forward stores a saved set for the backward in `light` (default) or `tape` mode; a no-save forward pairs with a checkpoint-replay backward. This PR replaces the kernels of that variant with a faster version behind the same public entry points. The baseline is the previous Cake version of this kernel on main (#6787). The tables below list the latency of both versions and the speedup for 14 shapes on each of three GPUs. Across all shapes, GPUs and the forward, backward and checkpoint columns, the speedup ranges from 1.435× to 1.892×.

**NVIDIA GB300 (sm_103a, 152 SMs), CUDA 13.4**

| Shape (H, S) | fwd previous / this PR ms | fwd speedup | bwd previous / this PR ms | bwd speedup | ckpt fwd+bwd previous / this PR ms | ckpt speedup |
|---|---|---|---|---|---|---|
| P1 (H=4, S=239718) | 2.049 / 1.292 | 1.586× | 5.044 / 2.984 | 1.691× | 9.119 / 5.558 | 1.641× |
| P2 (H=4, S=245028) | 2.013 / 1.309 | 1.538× | 5.007 / 3.068 | 1.632× | 8.993 / 5.681 | 1.583× |
| P3 (H=4, S=249866) | 2.079 / 1.324 | 1.571× | 5.189 / 3.119 | 1.664× | 9.325 / 5.758
<!-- upstream-excerpt-end -->
