## 📌 Description

Add a CUTLASS backend for NVFP4 SVDQuant GEMM and linear operations on **SM120**, exposed through the existing `mm_nvfp4_svdquant` and `svdquant_linear` APIs with `backend="cutlass-sm120"`.

The backend combines the NVFP4 residual GEMM with a BF16 LoRA correction and provides a fused preprocessing path for complete SVDQuant linear layers. It complements the existing CuTe DSL implementation. On SM120, `backend="auto"` now compares CuTe DSL and CUTLASS candidates through the shared AutoTuner for both GEMM and complete linear, at ranks 32 and 64; CuTe DSL remains the untuned default.

The implementation includes:

- **Fused GEMM:** NVFP4 matrix multiplication with BF16 LoRA-up and optional bias, including Stream-K reduction handling.
- **Fused preprocessing:** BF16 smoothing, NVFP4 activation quantization, and rank-32 or rank-64 LoRA-down in one CUDA prefix kernel. Rank 64 offers the reusable row-major producer families; the packed-L2T, M537 and cuBLASLt prefix families remain rank-32-only, and their entry points reject other ranks.
