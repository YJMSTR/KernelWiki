## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Cake's MiniMax-H3 fused pre-attention (RMSNorm + AdaLN + quantize first stage, then QKV GEMM + Q/K RMSNorm + NeoX RoPE + destination-major pack) has five variants in FlashInfer, split by input data type: three on sm_100a / sm_103a and two on sm_120a. This PR delivers the MXFP8 variant (`MiniMaxH3Mxfp8PreAttention`). It now runs as two programs: the RMSNorm + AdaLN + MXFP8 quantize stage, then a fused MXFP8 QKV GEMM whose epilogue does the Q/K norm, RoPE and MXFP8 pack. The previous version ran a quantize stage, a separate CUTLASS MXFP8 GEMM and a pack stage. The new version accepts any token count M, where the previous one supported only a fixed set of (M, P), and its outputs are byte-identical to the previous version on every shape that version supports. The baseline is the previous Cake version currently on main, called through the same public entry with the same inputs, on the same GPU and in the same process. Against it, this PR is 1.36x–1.48x faster on GB300 and 1.32x–1.60x faster on GB200 across 24 shapes (M tokens per destination, P destinations; M x P is the total token count of the step).
