<!-- upstream-excerpt-start -->
`flashinfer.mega_mhc` (`prepare_mega_mhc`, programs under `flashinfer/experimental/deepgemm_mega_mhc`) contains programs for the fused manifold-constrained hyper-connection (mHC) inference step. Before this PR, it ships 18 programs:

- **Existing variants:** 14 hidden-5120 FP8-E4M3-output variants (shifted / unshifted, shared-scale, `col` / `extra` scale layouts, split counts 16 / 20 / 27 / 40) on `sm_100a` / `sm_103a`. On `sm_107a` it ships four programs: the hidden-4096 BF16-output program (`sf_layout="bf16"`); its tailpipe twin from the previous PR of this series (#7121), which the loader runs when the token count gives at most 22 splits (T >= 385 on a 208-SM GPU); and the hidden-4096 FP8 group-128 (`sf_layout="fp8_group128"`) and NVFP4 (`sf_layout="nvfp4"`) output variants.
- **This PR:** a third hidden-4096 BF16-output program on `sm_107a`. It is the weight-staging build of the tailpipe program: each CTA stages the RMSNorm weight once in shared memory, and the tail reads it from there.
