## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`flashinfer.fp8_batched_gemm.prepare_fp8_batched_gemm` dispatches the DeepGEMM-derived batched projection GEMM (`bhr,hdr->bhd`: per-head projection of T tokens over H heads from rank K=4096 to N=1024; FP8 variants take e4m3 operands with UE8M0 block scales) to one of six variants. This PR delivers all six as one self-contained package:

- `cake_deepgemm_batched_gemm_1931777936a4c257b75f`: FP8 operands, scaled (alpha) epilogue, BF16 output (general tile config)
- `cake_deepgemm_batched_gemm_8b30436f526588de8d13`: FP8 operands, N-tile 256 config, FP8 output
- `cake_deepgemm_batched_gemm_e8aa7f5b9aa0575db281`: FP8 operands, swapped-AB layout, M-tile 16 (small T), FP8 output
- `cake_deepgemm_batched_gemm_7e76dfdd9b10af2f8359`: FP8 operands, swapped-AB layout, M-tile 64, FP8 output
- `cake_deepgemm_batched_gemm_94affe3b74cd7c5a6422`: BF16 operands, T≥128 config, BF16 output
- `cake_deepgemm_batched_gemm_d9a9c12ba43e831e0a02`: BF16 operands, small-T (T=4) config, BF16 output
