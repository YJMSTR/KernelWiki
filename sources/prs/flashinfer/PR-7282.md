## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
FlashInfer's `mm_bf16_fp4` multiplies BF16 activations by FP4 (E2M1) weights that carry E4M3 block scales, with FP32 accumulation. Cake ships it as two backend variants that differ in operand layout. `blackwell-native` uses cuDNN-ABI layouts and produces BF16 or FP16 output. `blackwell-tiled` uses CuTe-ABI prepared-tile layouts and produces BF16 output. This PR regenerates 17 of the 97 Cake programs of this kernel: the small-M split-K programs and the large-M pair programs. They replace the previous Cake generation of the same kernels on `main` (#6614). That previous version is the baseline. Speedup is the previous time divided by this PR's time, with both measured on the same GPU. Speedup ranges from 1.000x to 1.119x on GB300 and from 1.004x to 1.166x on B200. The two 16/1024/1024 `blackwell-native` rows are essentially unchanged on both GPUs.

**NVIDIA GB300 (sm_103a), CUDA 13.4:** median CUPTI kernel time in us, cold L2, PDL on; alpha passed and BF16 output unless the variant column notes otherwise.
