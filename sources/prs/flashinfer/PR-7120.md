This PR adds a Cake backend for `flashinfer.comm.tp_moe_finalize_rmsnorm`, the tensor-parallel MoE finalize + RMSNorm collective (hidden size 4096, top-8 experts). The kernel has two routing-weight data types (BF16 and FP32 `expert_weights`) and two norm orders (`weight_before_norm` true and false); Cake ships five program kinds, selected by world size and token count. The tables below show the BF16, `weight_before_norm=True` variant at TP4 on GB300 and TP8 on B200, compared with FlashInfer's existing CuTe DSL kernels (PR #6544). T is the token count, and speedup = baseline µs / Cake µs.
