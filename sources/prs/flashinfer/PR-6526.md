## Summary

Regenerates the batched FP8 GEMM family `flashinfer.experimental.deepgemm_batched_gemm` (public API `flashinfer.fp8_batched_gemm.prepare_fp8_batched_gemm`) for SM100a (B200) and
SM103a (GB300) at FlashInfer `3637083a3`. The swap-AB batched FP8 programs (the BM16 / 12-stage and BM64 / 10-stage geometries) load the B operand and its scale factors (SFB) with the `evict_first` L2 cache hint. A and SFA keep the default policy, and the bytes loaded, their addresses, the mbarrier transaction counts and the arithmetic are unchanged. The three FP8-output cohort rows that run these programs change (model-batched-projection-t1-fp8 / -t16-fp8 / -t128-fp8, launch counts unchanged); the other four batched rows keep the kernels of the previous delivery: this export re-renders their program files (the typedef, tensor-map-ABI and device-helper preamble moves into the shared `cake_deepgemm_batched_gemm_device_common.cuh` and `csrc/cake_device_helpers/` headers, the launch bounds and shared-memory offsets become macros, and the host shims share `cake_deepgemm_batched_gemm_host_common.cuh`), and once the hashed kernel name and those macros are expanded their kernel bodies are the same text
