## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
The Cake-generated MiniMax Sparse Attention (MSA) kernels for Blackwell in FlashInfer ship 31 route variants on each of sm_100a and sm_103a: 9 decode routes, 12 prefill union routes (bf16/bf16, bf16-q/fp8-kv and fp16/fp16, flat and paged), 6 long-context bf16 reverse prefill routes (main and reduce passes), and 4 Top-K select routes. This PR delivers new program versions for 9 of these routes per architecture and adds or removes no route. The bf16/bf16 union prefill routes flat gqa16, flat gqa8, paged gqa16 (any, causal_large, causal_mask64) and paged gqa8 run a persistent heavy-first tile loop over GQA-folded tiles, the two bf16-q/fp8-kv gqa0 union prefill routes gain only a shared-memory proxy fence, and `topk_select_streaming` uses an 8-warp rank-count merge and a shared-memory-staged scan row. The baseline is the reference MiniMax Sparse Attention kernels of vllm-project/MSA `dev` @ `968061ab` (package `fmha_sm100`), using the fastest admissible route per row (`msa_prefill_cute` or `msa_prefill_csrc` for prefill rows, `msa_topk_hkt` or `msa_topk_thk` for Top-K rows); it is a non-Cake baseline because the previous Cake version of these routes on `main` was not measured per shape
<!-- upstream-excerpt-end -->
