`flashinfer.mega_mhc` (`prepare_mega_mhc`, programs under `flashinfer/experimental/deepgemm_mega_mhc`) contains programs for the fused manifold-constrained hyper-connection (mHC) inference step. Before this PR, it ships 19 programs:

- **Existing variants:** 14 hidden-5120 FP8-E4M3-output variants (shifted / unshifted, shared-scale, `col` / `extra` scale layouts, split counts 16 / 20 / 27 / 40) on `sm_100a` / `sm_103a`, which this PR does not change. On `sm_107a` it ships five hidden-4096 programs. Three have BF16 output: the BF16 program (`sf_layout="bf16"`); its tailpipe twin, dispatched when the token count gives at most 22 splits (T >= 385 on a 208-SM GPU); and the weight-staging tailpipe twin, dispatched at 16 splits or fewer when the grid runs five or more waves (T >= 3329 on 208 SMs). The other two are the FP8 group-128 (`sf_layout="fp8_group128"`) and NVFP4 (`sf_layout="nvfp4"`) output variants.
