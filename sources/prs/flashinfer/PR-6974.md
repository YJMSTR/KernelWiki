## Summary

This PR is the round-2 deslop of the Cake Blackwell MLA code for SM100 / SM103, tracked in #6670. It covers two families:
- `cake_trtllm_mla_blackwell`, the Cake decode backend of the TRT-LLM-style MLA decode path;
- `cake_kimi_k3_mla`, the Kimi-K3 FP8 paged MLA decode.

Commit 1 keeps one host binding per trtllm decode domain, so the SM100 binding of each domain also serves its SM103 family. Commit 2 drops the dead one-variant route selector from each binding. Commit 3 drops three registry fields that nothing reads. Commits 4-7 fold four trtllm kernel pairs onto one kept source each: the 007826 pair, the two tail kernels, vhalf into vquarter, and the CLC pair. Commit 8 folds the three kimi reducer sources into one. It also keeps one kimi binding for the reducers and one for the row tiles. Every former kernel symbol stays defined for its program.
