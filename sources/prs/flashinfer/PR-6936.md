## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`flashinfer.diffusion_ops.minimax_h3_sm120_varlen_attention_nvfp4(..., pv_mode="fp4")` is the public SM120 NVFP4 entry for MiniMax-H3 packed-varlen attention. This PR adds the opt-in `pv_mode="fp8"` variant (called "hybrid" below). It uses NVFP4 Q/K and FP8 P·V in three launches. The default `pv_mode="fp4"` is unchanged byte for byte. The baseline is the previously delivered FP8 operator `minimax_h3_sm120_varlen_attention_fp8`. The hybrid is faster than that operator on every gated row. On RTX 5090 the speedup is min 1.3632x and geomean 1.3814x. On RTX PRO 6000 Blackwell Server Edition it is min 1.1806x and geomean 1.1876x. The min and geomean cover two sessions per GPU, and the tables show session 1. The variant exists for accuracy. On the gated rows, its rel-L2 against the FP32 oracle is 0.136-0.143, compared with 0.186-0.193 for the default route. The default route is still faster, as the default / hybrid column shows.

Latencies are whole-operator medians in ms (BF16 in to BF16 out, including quantization) of the packed-varlen attention. Shapes are the production center / tail / padding token counts at P=1.

**NVIDIA GeForce RTX 5090, `sm_120a`, driver 620.62, CUDA 13.0 toolkit
<!-- upstream-excerpt-end -->
