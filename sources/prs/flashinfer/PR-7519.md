## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`cake_tinygemm2_tcgen05` is the Cake backend of `flashinfer.gemm.tinygemm_bf16`, which computes BF16 `out = input @ weight.T (+ bias)` for small batches. It contains generated tcgen05 programs and supports BF16 only, with and without bias and with and without PDL. #7302 added the backend, and #7370 unrolled its narrow tile and retuned its windows. This PR regenerates the programs and retunes the routing. Every tile now frees its tensor memory right after the epilogue's last tensor-memory read, and the narrow tiles overlap barrier initialisation with the tensor-memory allocation. The per-chain-accumulator tile (64 batch rows per CTA) swaps its MMA operands: the activations are now the M=64 A operand and the weights the N=32 B operand, and each lane writes its 16 outputs as one 32-byte store. The host routes this tile only when `out` is 32-byte aligned (`out.data_ptr() % 32 == 0`). Otherwise the call keeps the kernel it would have run anyway, which returns the same bits. The PR also adds two M=64 packed tiles (16-row and 4-row).
