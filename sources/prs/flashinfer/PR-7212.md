## 📌 Description

Builds on the merged #7204 and targets `main`. The parent squash merge has been reconciled without changing any of the 17 qualified feature files; their contents match the previously tested head. Auto-merge remains disabled until this head is reviewed and required CI passes.

Add grouped per-tensor E4M3 and DeepSeek block-FP8 Tensor Core candidates to the opt-in Frost low-latency backend on SM90 and SM120, and extend the SM120 BF16/FP16 candidate set to additional gated activations. The original checkpoint layout, live scales, common activation lowering and ordered combine remain shared with the existing implementation.

| SM120 per-tensor FP8 → BF16 | Default SwiGLU/SiTU/ReLU2 at T4/T8; native warp FP8 MMA group2 or group4/stages2/K128 |
