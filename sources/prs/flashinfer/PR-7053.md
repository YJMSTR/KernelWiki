## 📌 Description

Extend the opt-in `FrostLowLatencyConfig` backend to NVFP4 weights/activations and all ten typed activations for MXFP4/MXFP8 weights with MXFP8 inputs. Previously, the MX low-latency pipeline accepted SwiGLU only and the unified low-latency backend had no NVFP4 binding.

- Reuse the shared FMA device kernels for NVFP4, with FC1 widths 2/4 and raw or finalized outputs. Preserve the existing legacy adapters' arithmetic.
- Support gated and non-gated MX activations in both Tensor Core and FMA tactics; non-gated preparation stores only the required FC1 rows. Activation parameters participate in compilation keys.
- Use round-to-nearest division for unified NVFP4 intermediate quantization at exact E2M1 midpoints, with deterministic positive and negative midpoint regression tests.
- Add preparation/API documentation, changing-input CUDA Graph tests, and a standalone native-tactic comparison benchmark.
