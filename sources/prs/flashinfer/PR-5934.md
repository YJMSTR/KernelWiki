## Summary

Closes #5802.

Mechanical deslop of the request-ordered paged-decode sub-product (`csrc/cake_fmha/request_ordered_paged_decode`, sm_103a only). The three commits remove modules no public call can select, collapse the six fallback clones into one program, and replace the 12.6K-line benchmark ledger with a module table. No kernel body changes: each surviving program instantiation compiles to the same SASS as the file it replaces.
