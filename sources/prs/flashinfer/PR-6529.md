## 📌 Description

1. **Share compiled kernels across processes:** persist kernels for all PrimTS attention families and metadata inspectors through FlashInfer's existing CuTe DSL disk cache.
2. **Cache occupancy queries:** reuse successful results per device/cluster size, retaining existing fallbacks.
3. **Enable native BF16 decode output:** support FP8 Q with FP8/NVFP4 KV across supported variants. Fix reduction eligibility and trace output dtypes; BF16 retains FP16's automatic tactic eligibility.

GB300, PyTorch 26.08 measurements:

- Disk cache, DSL 4.7, [eight-case public cohort](https://github.com/PerkzZheng/flashinfer/blob/291ef8096b6dd0996c9abbb1459ea7dad54b3fc6/tests/attention/test_attention_ts_compile_cache.py) at `291ef8096`: median fresh-process setup/test time **65.58 → 3.16 s** with a warm cache; cold cache **69.71 s**. Framework imports excluded.
- Native BF16, DSL 4.8, FP8 Q/KV, B4/SQ4/Hq16/Hkv1/D128/page128/KV4096/dense: **9.89 → 6.68 us** versus FP16+cast (`74402b69e` → `9c4f94cfc`). Warm-L2 CUDA graphs: 32 calls, 5 warmups, median of 5 × 100 replays; timing per call. Reproducer: #6569.
