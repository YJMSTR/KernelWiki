## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
The kernel behind `minimax_h3_fp8_pre_attention` and `minimax_h3_nvfp4_pre_attention` has 6 variants in this module on sm_120a: FP8 E4M3 or NVFP4 input, each with bf16, e4m3 or nvfp4 output. This PR changes the tile order (the raster order of output tiles) of two NVFP4-input GEMM programs. On the RTX PRO 6000, 6 of its 16 rows change: NVFP4 input with bf16 output at all six M. On the RTX 5090, 7 of its 16 rows change: NVFP4 input with bf16 output at all six M, and NVFP4 input with e4m3 output. Every other shape runs the same kernels as on main. The baseline is the previous Cake version of the kernel, which is the current FlashInfer route of these two entry points. The speedup is 1.0180x to 1.0224x on the RTX PRO 6000 and 1.0403x to 1.0494x on the RTX 5090. In both tables, the speedup column is the session's median per-group ratio, so it can differ slightly from the ratio of the two times beside it.
