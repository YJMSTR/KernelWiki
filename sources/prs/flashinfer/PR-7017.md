## Summary

This PR is round 2 of the Cake device-helper cleanup tracked in #6672. It covers three exporter-generated experimental Cake families for SM100 / SM103: the Kimi-K3 FP8 projection GEMM, the NVFP4 paged MLA decode and the MiniMax-H3 varlen attention. Each of these families now takes every device helper from the repository helper directory, `csrc/cake_device_helpers/`. The 50 package copies that are token-identical to a repository header are deleted: 24 from kimi and 26 from MLA decode. The three helpers that had no repository twin move into `csrc/cake_device_helpers/` with their names and bytes unchanged. This PR also deletes three headers of that directory that no translation unit includes. No include line changes. Loaders, registries, module names, compile definitions, launch parameters, bindings, kernel sources, tests, benchmarks and docs do not change. The only text edit is one sentence of the kimi package's `csrc/README.md`.
