## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR speeds up the BF16 rank-major expert-parallel (EP8) layer of the `MoEEpLayer` mega backend for SM100 (`flashinfer/moe_ep/kernel_src/blackwell_bf16_rank_major/`), which Cake generates. The layer uses BF16 activations, weights and output, with hidden size 7168, intermediate size 2048, 256 experts (32 per rank), top-8 routing, 8 ranks and 1 to 128 tokens per rank. It has one variant (BF16, rank-major, sm_100a). This PR changes only the stages around the GEMMs; FC1 and FC2 are unchanged. For up to 32 tokens per rank, dispatch and combine no longer stage data through barriers. Each sender writes 8-byte words, each holding a 4-byte payload and a 4-byte epoch, directly into the owner rank's receive bank, and the receiver polls those words. Two banks alternate by epoch parity, and a system-scope release/acquire pair orders their reuse. The epoch never takes the value of a freshly zeroed bank, and every rank clears the other bank before the 32-bit epoch wraps. A forward on this path launches six kernels.
