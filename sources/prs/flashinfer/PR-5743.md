## 📌 Description

Adds **PowLU-GLU**, a power-adaptive gated activation
(`use_power_adaptive_activation`), to the CUTLASS fused-MoE backend — across every quant
variant the backend compiles (BF16 / FP8 / NVFP4 / MXFP8 / MXFP8×MXFP4 / W4A16 / W4A8 /
Humming), via the shared activation kernel code:

```
PowLU(g) = g > 0 ? g^(m / (sqrt(g) + 1)) * sigmoid(g) : g * sigmoid(g)   # negative half is SiLU
out      = min(PowLU(gate), limit) * clamp(up, -limit, limit)            # clamp after the activation
```

- Adds `ActivationType::PowLU = 11` (`InvalidType` → 12) in all three enum copies, the
  serializer, and **both** `isGatedActivation()` predicates — the CUTLASS copy in
  `moe_gemm_kernels.h` is the one that drives GEMM1's `N = 2·inter_size` and workspace sizing.
- Implements `PowLUAdaptor` (fp32, element-wise sign branch, `__powf`), wired into
  `doGatedActivation`'s dispatch and `doActivation`'s enum-indexed `fn_list`, which gains a
  bounds check against out-of-range enum values.
- **No `ActivationParams` ABI change**: `m` rides the generic per-expert `swiglu_alpha` slot
