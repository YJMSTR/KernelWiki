## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`cake_rmsnorm_train` is Cake's RMSNorm training kernel: one data type (BF16 activations and weight, FP32 `rstd` and deterministic FP32 `dweight`) in four variants, plain and residual-fused, each forward and backward. This PR changes the plain backward (`dx`, `dweight`) at H=1536 and H=4096 for row counts above T=1024 and T=256 respectively on sm_100a / sm_103a, and above T=2048 and T=1024 on sm_107a. The new cooperative persistent programs stage the `dy` / `x` rows through a `cp.async.bulk` + `mbarrier` shared-memory ring and keep the previous backward's dot product and deterministic fixed-order FP32 `dweight` reduction under the same numerical contract; the forward and the other hidden sizes are unchanged. Against the previous Cake version (PR #6792), the new backward is 1.08-1.13x faster on B200, 1.08-1.13x on GB300 and 1.03-1.22x on R200, and forward + backward is 1.05-1.08x, 1.05-1.08x and 1.02-1.13x faster.

Both versions run in the same process on the same GPU. Latencies are CUPTI kernel-active times (T x H input, cold L2 before every launch), each the median of 3 counterbalanced paired groups. `bwd` is the backward, `step` is forward + backward, and Speedup = previous / new
<!-- upstream-excerpt-end -->
