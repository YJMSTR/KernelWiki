## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Cake's StepFun SwiGLU fused MoE (hidden 4096, intermediate 1536, 64 experts, top-k 8) comes in five data-type variants: bf16, fp8 (e4m3), mxfp8, nvfp4 and per-token NVFP4 (`nvfp4_bf16tok`). It is built from 113 kernels per architecture. This PR delivers the MXFP8 family's new tile-128 FC1 (+SwiGLU) and FC2 kernels. With them, the default plan now selects tile 128 at 1024 tokens; before, it could only pick tile 64 or 256. The baseline is the previous Cake version of this kernel, the package on FlashInfer main from #6934.
