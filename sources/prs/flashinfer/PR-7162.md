## 📌 Description

Extend the existing explicit `frost_low_latency` candidate to ordinary per-tensor E4M3 FP8, and enable the shared BF16/FP16/per-tensor-FP8 FMA pipeline on SM90. The two FMA kernels reuse the dense16 schedule and compiled FFI binding: FC1 fuses activation/static requantization, and FC2 fuses the slot-ordered combine. No default backend selection changes.

The new FP8 path preserves static checkpoint calibration and the CUTLASS per-tensor BF16 FC1 preactivation boundary. It supports the existing ten typed activation classes, T=1–8, top-k ≤ 32, H divisible by 128 and I divisible by 32 (physical padding to 128). Scales remain runtime tensors across graph replay and rebinding. Quantized output remains BF16. SM90 rejects MX/NVFP4 and integer Tensor Core tactics.

On RTX PRO 6000 Blackwell Workstation Edition (SM120), H2048/I512/E512/top-k10, FP8 SwiGLU, CUPTI measures the full routed-expert GPU pipeline with precomputed routing. All 21×21 advertised CUTLASS stage pairs plus default and 16 Frost tactics were searched, with frozen-winner ABBA validation:
