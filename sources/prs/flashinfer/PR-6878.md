## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`flashinfer.mm_nvfp4_svdquant(..., backend="cake")` computes the NVFP4 SVDQuant GEMM `out = BF16(alpha * (deq(A) @ deq(B)^T + D @ L1^T) + bias)`. In this kernel, A and B are NVFP4 (E2M1) with E4M3 block scales. The low-rank D / L1, the bias and the output are BF16, and accumulation is FP32. Its Cake backend has one data-type / layout variant, with two fused forms (with and without the fused bias), across LoRA ranks 32 / 64 / 96 / 128. This PR delivers that whole variant for sm_100a and sm_103a as the vendorable package `flashinfer/cake_nvfp4_svdquant_gemm_backend`. The package has 15 programs and replaces the 7 Cake programs shipped before. All latencies are CUPTI kernel-active medians, with L2 cleared before every launch. "Previous Cake" is `backend="cake"` on main at this PR's base. "CUTLASS" is that backend's fastest autotuned tactic. Both were measured in the same session as this PR.

**NVIDIA B200 (sm_100a), CUDA 13.4**
