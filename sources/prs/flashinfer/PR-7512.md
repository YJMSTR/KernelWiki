## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR adds 20 in-module cake_fmha programs for paged context (prefill) attention. They run behind the existing `trtllm_batch_context_with_kv_cache(backend="cake")` route and replace the previous Cake context route for the shapes they cover. The kernel uses head dim 128 and a bottom-right causal mask. It has three data-type variants, and this PR delivers all three for sm_100a and sm_103a:

- BF16 (Q / KV / O in BF16): 4 shape classes, 6 programs.
- FP8 E4M3 (Q / KV / O in FP8), host or device scales: one exact shape class plus 8 runtime-size programs for shapes outside the exact classes, 10 programs.
- FP8 Q with NVFP4 KV (FP8 O), host or device scales: 4 programs.

Shapes with LSE output or attention sinks keep the existing route. The baseline is the previous Cake route on FlashInfer main (872554187) for the same call. Speedup = previous Cake time / this PR time, so a value above 1 means this PR is faster. Times are per-call latencies in microseconds, measured with CUDA events. The bracket gives [min, max] over the 5 page-table layouts.

### B200 (sm_100a)

Context shapes. NVIDIA B200, sm_100a, CUDA 13.4, driver 580.82.07. Median of 5 page-table layouts.
