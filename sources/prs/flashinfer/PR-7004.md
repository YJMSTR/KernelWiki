## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`flashinfer/experimental/cake_rubin_mla_nvfp4_decode` is the Rubin (SM107, `sm_107a`) variant of the Cake NVFP4 MLA paged decode. Cake is NVIDIA's kernel generator. On compute capability 10.7, `flashinfer.mla.cake_mla_nvfp4_paged_decode` routes to this package. It decodes BF16 queries against the paged NVFP4 MLA KV cache (352 B per token) and writes BF16 output. This PR makes the decode and the split-KV merge launch under programmatic dependent launch when the plan splits the KV. The query quantizer and the decode now signal their dependents as soon as their work is done, so the three launches of one decode call overlap their prologues. The public API, cache layout and numerics are unchanged, and outputs match the previous version bit for bit, except at the largest-batch split-KV rows where the previous version is itself not run-to-run deterministic (its merge sums the split partials in a nondeterministic order). The baseline is the previous version of this package, which FlashInfer `main` ships (merged in #6931). It was measured in the same process on the same board, interleaved with this PR.
