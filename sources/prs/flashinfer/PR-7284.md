## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR adds the compute capability 10.7 variant of `cake_qsa_nvfp4`. The kernel is the sparse paged GQA decode over an NVFP4 KV cache, with bf16 queries, NVFP4 paged keys/values, and both `NHD` and `HND` layouts. It is reached through `flashinfer.sparse.qsa_sparse_paged_attention(..., backend="cake")`. The kernel has two device programs. The mma.sync program covers compute capability 8.x / 9.0. The tcgen05 program covers compute capability 10.0 / 10.3 and, with this PR, 10.7. Each program has a split form (decode + merge kernels). On 10.0 / 10.3 there is also a fused (cooperative) form, used on aarch64 hosts at 4 or fewer query rows outside a stream capture; 10.7 keeps the split form on every host (its fused form measured no faster at any row). This PR compiles the tcgen05 decode (plain and cooperative) and the merge for `sm_107a`. Their device text is the same as the 10.0 / 10.3 units except for the shared-memory descriptor field. There is no earlier Cake version of this kernel for 10.7, so the baseline is FlashInfer's own `qsa_sparse_paged_attention` reference backend built for the device.
