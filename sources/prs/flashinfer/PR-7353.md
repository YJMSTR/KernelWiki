## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`cake_qsa_nvfp4` is Cake's QSA NVFP4 sparse paged decode attention kernel. It has seven program variants:

- `decode` (mma.sync K-first; sm_80, sm_90a, sm_120a)
- `decode_whole_tile` (mma.sync whole-tile issue schedule; sm_80, sm_120a)
- `decode_coop` (mma.sync fused co-resident split merge; sm_80, sm_90a, sm_120a)
- `decode_tcgen05` (tcgen05 plain split decode; sm_100a, sm_103a, sm_107a)
- `decode_tcgen05_coop` (tcgen05 fused; sm_100a, sm_103a, sm_107a)
- `decode_tcgen05_persistent` (persistent balanced tile walk; sm_103a, sm_107a)
- `merge` (split-KV merge with LSE and gate; all six architectures)

This PR adds the persistent balanced tile walk for compute capability 10.7 (sm_107a). Compute capability 10.7 runs only the split form. The route picks the persistent walk for split-form calls when the plain grid needs more than one resident wave but no more than three. All other calls keep the previous route bit for bit. The baseline is the previous Cake version of the same route, which is the package on upstream main before this PR. On compute capability 10.7, that route is the plain tcgen05 split decode followed by merge. At 128 rows with eager launches, the speedup is 1.17x for NHD
