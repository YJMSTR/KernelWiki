## 📌 Description

Extend Frost weight-only NVFP4, MXFP4, MXINT4 and E4M3 to FP16 inputs/intermediates and independently selected BF16/FP16 outputs. Reuse the existing two-kernel FMA pipeline, typed activations, preparation and ordered combine. Quantized-activation FP8 keeps its previous contract.

Expose qualified FP16 wide-load choices and Hopper FC1 route groups. Also improve the native SM120 FP16/NVFP4 comparator: direct routing through T=8 is bounded to H<=2048, I<=512, top-k<=10; larger experts retain their existing packing policy. The default Frost backend list is unchanged.
