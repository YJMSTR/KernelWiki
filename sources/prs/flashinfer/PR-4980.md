## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Developed by the **CAKE team**, the kernels in this PR **outperform** the relevant **SOTA baselines at the time of merge** on the **vast majority of performance benchmark shapes**, matching them otherwise.

This change adds a `cake_fmha` backend for TRTLLM paged decode and context
attention on Blackwell. The explicit entrypoints and `backend="cake"` selector
use standalone CUDA implementations with authenticated manifests, launch
bindings, and exact `sm_100a` / `sm_103a` source selection.

The API contract is pinned to FlashInfer revision
`5b8da12050f80a5b5cb2bab9e87d9635a8872e5b`. Coverage is 57,280 valid API
cells: 1,798 optimized selections and 55,482 standalone compatibility
selections. The optional 25-variant decode/context add-on shares the manifest
and JIT interface with 74 base variants. D256 FP8 speculative decode supports
Q1 through Q8 and initializes dynamic shared-memory attributes per device.

The sink schedule selects five KV stages on B200 and six on GB300. Current
source measurements use the pinned public TRTLLM API, three alternating-order
rounds, cold L2, and CUPTI GPU timing:
