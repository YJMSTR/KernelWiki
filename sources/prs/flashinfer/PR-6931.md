## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR adds the Rubin (SM107, `sm_107a`) variant of the Cake NVFP4 MLA paged decode. Cake is NVIDIA's kernel generator. It already ships this decode for SM100 / SM103 (B200 / B300) as `cake_mla_nvfp4_paged_decode`. This PR adds the Rubin package, `flashinfer/experimental/cake_rubin_mla_nvfp4_decode`. On compute capability 10.7, `flashinfer.mla.cake_mla_nvfp4_paged_decode` routes to it. The package contains mixed-tile and full-tile decode programs, three split-KV merge programs and the NVFP4 query quantizer. It decodes BF16 queries against the paged NVFP4 MLA KV cache and writes BF16 output. The baseline is TokenSpeed MLA 2 (2.0.3), a non-Cake kernel measured in the same process on the same board. Over the 16 configurations below, the geometric mean of MLA 2 / Cake is 1.044: 1.104 on the Q4 rows and 0.987 on the Q8 rows. Cake is faster in 9 of 16 configurations. On the Q4 rows it is faster at batch 4 and above, and it is slower at batch 1.
