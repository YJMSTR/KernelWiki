## 📌 Description

Integrates the TRTLLM-Gen sliding-window FMHA metadata and runtime contract into
FlashInfer.

This change:

- adds fixed left/right window propagation for the direct TRTLLM-Gen context API;
- adds per-query-token inclusive `VariableWindow` start/end bounds;
- updates paged and ragged launcher parameter plumbing and trace schemas;
- selects and hashes the new mask metadata while preserving the existing causal fast path when a
  configured left window covers the complete KV sequence;
- centralizes C++ validation for causal, non-causal, fixed-window, variable-window,
  and chunked-attention combinations;
- preserves compatibility with generated metadata headers that spell the
  FP16-softmax/Spcompress slots either semantically or as `mReserved1/mReserved2`;
- adds Python validation and regression coverage for unsupported or malformed
  configurations; and
- preserves existing dense, causal, MLA-generation, and chunked-attention behavior.

The public wrapper continues to reject non-causal sliding-window attention for
the TRTLLM-Gen paged backend. The direct context API supports explicit
two-sided non-causal windows. `VariableWindow` requires an inclusive start/end
pai
