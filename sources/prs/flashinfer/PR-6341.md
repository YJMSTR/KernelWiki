## Kimi-K3 NVFP4 SiTU experts: SM100 8192/16384-token rows with the 8-bit per-tile FC2 partial

On SM100 (B200) the 8192- and 16384-token rows now run the 8-bit per-tile FC2 partial route that #6248 introduced for SM103: an FC2 that stores its result as a signed INT8 partial with one FP32 scale per 128×128 tile and the stream-ordered finalize that consumes it, instead of the pre-shuffled scale-factor route (the scale-factor writer, the FC1 that loads its images, the BF16 expert output). The SM100 programs are the SM100 kernels of the same sealed, measured export whose SM103 kernels #6248 carries. Trade-off, as on SM103: run-to-run bitwise reproducibility of the output is lost on these four rows (tile membership, hence each tile's scale and rounding, depends on the atomic-counter row assignment of the call); outputs stay within the reference tolerance (`atol=1.0, rtol=0.1`) of the previously shipped route on every measured round, and the quantization-added error versus the previous route is reported with the measurement. Every other token count is unchanged on both architectures. This change is stacked on #6340 (the SM100 single-token fused FC1 change) and, through it, on #6329, #62
