## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`flashinfer/experimental/cake_rubin_mla_nvfp4_decode` is the Rubin (SM107, `sm_107a`) variant of the Cake NVFP4 MLA paged decode. Cake is NVIDIA's kernel generator. On compute capability 10.7, `flashinfer.mla.cake_mla_nvfp4_paged_decode` routes to this package. It decodes BF16 queries against the paged NVFP4 MLA KV cache (352 B per token) and writes BF16 output. This PR adds a fourth split-KV merge form, which merges one output row per CTA with eight warps and a 64-slot load round. The host now picks the merge form from the number of output rows and the number of split partials per row: eight warps per row up to 384 rows, or up to 2048 rows when a row has more than 32 partials, and otherwise the fewest warps whose one load round holds the partials. For a request whose rows fit one tile, the split plan now fills one wave of CTAs instead of stopping at the cost model's first minimum. Of the 74 configurations below, 14 take a different plan or merge form than before; the other 60 keep theirs.
