## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
The Cake Blackwell MSA (MiniMax sparse attention) M16 sparse decode kernel in `flashinfer/msa_ops` ships six variants: BF16 query/KV, FP16 query/KV, and BF16 query with FP8 (e4m3) KV, each in a flat and a paged KV layout. This PR re-renders the family from its current source and adds a seventh variant. It is a paged BF16 decode program whose K and V TMA copies carry the L2 `evict_first` cache hint. On sm_100a and sm_103a, the dispatcher selects it only when the batch fits two work items per SM (items <= 2 * num_sms) and the longest KV page count is at least 320 pages. Every other shape keeps the unhinted paged program. The baseline is the previous Cake version of the kernel, the unhinted paged BF16 decode program already in FlashInfer main. Against it, the new variant is 1.127x faster on B200 and 1.126x faster on GB300 (geometric mean over 6 shapes). Latencies are the median of CUPTI-traced GPU time with a cold L2. Both sides and the MiniMax reference implementation (`nv_dev` branch, the `nvdev_decode_bf16` columns) were measured in the same job.
