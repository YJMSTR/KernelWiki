## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`cake_concat_mla_k` is the Cake export of FlashInfer's MLA key concatenation (`concat_mla_k` with `backend="cake"`). For each token t and each of 128 heads, it writes `K[t, h] = [k_nope[t, h, 0:128] | k_rope[t, 0:64]]`, broadcasting the RoPE row to every head. It is a byte copy with no floating-point arithmetic, and one element-width dispatch makes it byte-exact for BF16, FP16, E4M3 and E5M2. One kernel source generates two launch programs: ONE_CTA (one CTA per token window; sm_100a, sm_103a, sm_107a) and SPLIT (several CTAs share one token window; sm_107a only). This PR re-exports both programs through the in-tree program loader as one self-contained kernel + binding unit pair per program, replacing the previously shipped Cake units. The device code is unchanged, so the expected speedup is ~1.0x. "Previous" is the previously shipped Cake version of this kernel (the loader shipped before this PR), and "new" is this PR's export. Times are the median GPU kernel time (CUPTI activity tracing, cold L2) over 3 interleaved groups x 128 iterations, with speedup = previous / new.
