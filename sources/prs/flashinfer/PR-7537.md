## Description

Cake generated the cake_blackwell_msa family with one source file per program, so the tree has many near-duplicate CUDA files. This PR moves them into shared translation units. Each program chooses its variant with `-D` defines on its compile line. The dense loader becomes a table. The 36 dense host bindings become one binding per argument plan. The per-architecture topk_select pair becomes one program. The flat/paged and L2 evict-first kernel twins become one source per schedule. The 14 NVFP4 host launchers become one launcher per route.

The dense family targets B200 (SM100, sm_100a) and GB300 / B300 (SM103, sm_103a). The NVFP4 package (`msa_nvfp4_decode`) targets R200 (SM107, sm_107a). For the whole PR, `git diff --shortstat --no-renames` from base to HEAD gives `81 files changed, 4084 insertions(+), 42239 deletions(-)`. The per-commit stats below don't add up to this total because some files change in more than one commit, and those changes net out across the range.
