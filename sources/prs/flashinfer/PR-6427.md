## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
The Cake fused MoE routing gate (`flashinfer.experimental.deepgemm_mega_gate`, public API `flashinfer.mega_gate.prepare_mega_gate`) is one persistent BF16 kernel. It computes the router GEMM `x[M,K] @ weight[E,K]^T` with FP32 accumulation and applies `sqrtsoftplus` scoring with an FP32 expert bias. It then selects the top-6 of E = 384 experts (K = 5120), normalizes and scales the unbiased weights, and returns int64 physical expert indices `[M, topk(+shared)]` with FP32 weights. The kernel source exports 16 schedule templates, each compiled as one program. They differ in block tokens, MMA CTA pairing (single CTA or a `cta_group::2` pair), split-K count, expert groups, pipeline stages, gate warpgroups and K-block merge. The templates cover the single-token 16-way cluster split-K route, the 2..4-token cluster route, exact-shape programs for the production token counts 1, 3, 16, 128 and 512 and for the 2..16-token logical-output route, runtime programs for every other token count, and the deterministic (split-K-free) routes.
