## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
The MiniMax-H3 noncausal packed-varlen attention kernel works on THD tensors ([tokens, 56 heads, 128 head dim]), with BF16 input and output and int32 `cu_seqlens`. It has seven Cake variants in FlashInfer, in BF16, FP8 and NVFP4-QK forms. This PR delivers a new version of two of the sm_120a NVFP4-QK forms, which use the SageAttention3 FP4 recipe. These are `minimax_h3_sm120_varlen_attention_nvfp4` (default, with the in-kernel mean compensation) and `minimax_h3_sm120_varlen_attention_nvfp4_nodelta` (opt-in, uncompensated). The API is the same. The programs of the NVFP4-QK / FP8-PV form selected by `pv_mode="fp8"` do not change. The previous version was one hand-written translation unit. This PR replaces it with 13 generated programs (pre-processing, statistics / quantization and attention launches). In these programs:

- The statistics launch also quantizes Q, so the quantizer handles only K and V.
- The fused pre-processing of mid-size plans runs 3 CTAs per SM.
- In the fused plans, each head's attention starts as soon as that head's pre-processing is done (overlapped form). This applies on 170 and 188 SMs.
