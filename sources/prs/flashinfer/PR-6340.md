## Kimi-K3 NVFP4 SiTU experts: SM100 single-token row with the fused quantization + routing FC1

On SM100 (B200) the single-token row (M = 1) now launches the three-stage fused route that SM103 already uses since #6194: the FC1 fuses the activation quantization and the expert routing into its prologue, so the four-stage route (separate fused quantization + router kernel, then the FC1) is superseded on both architectures. The SM100 FC1 is the SM100 twin of the fused program delivered for SM103 in #6194, taken from the same kind of sealed, measured export; the FC2 and finalize kernels of the row are unchanged, and so is every other token count on both architectures. The exported kernels are bitwise identical to the generating source build and to the previously shipped route on every measured round (BF16 output compared exactly, intermediates exact), so there is no numerical trade-off. This change is stacked on #6329 and, through it, on #6248 and #6194; the PR diff therefore includes those commits until they merge.
