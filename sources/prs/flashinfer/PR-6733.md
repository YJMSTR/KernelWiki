> Developed by the **CAKE team**, the kernels in this PR **outperform** the relevant **SOTA baselines at the time of merge** on the **vast majority of performance benchmark shapes**, matching them otherwise.

## Summary

This PR cleans up the three Cake-generated DeepGEMM-signature MQA logits families under `csrc/experimental/` and `flashinfer/experimental/`:

- Dense and paged: `deepgemm_dense_mqa`, sm_100a/sm_103a.
- SM120 paged: `deepgemm_sm120_paged_mqa_logits`, sm_120a.
- Sparse: `deepgemm_sparse_mqa`, sm_100a/sm_103a.

The public shims are `flashinfer/{dense_mqa,paged_mqa,sparse_mqa,sm120_paged_mqa_logits}.py`.

The PR has six commits:

1. Ship the SM100/SM103 dense and paged catalog in wheels. Before this fix, a non-editable install raised `FileNotFoundError` the first time any dense or paged entry point read the catalog.
2. Drop catalog data that no code reads. The SM120 catalog goes from 7,415 to 4,037 lines and the dense catalog from 5,807 to 5,138.
3. Drop the dead `logits_dtype` and `use_unaligned_ks` plumbing.
4. Replace the three per-family host headers, and the 35 inlined copies of the same helper, with one shared header.
5. Fold the 30 SM120 per-route logits kernels
<!-- upstream-excerpt-end -->
