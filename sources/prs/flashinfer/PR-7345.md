## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR adds the SM120 build of the whole-tile decode to the Cake backend of `flashinfer.sparse.qsa_sparse_paged_attention`. The kernel computes gated sparse paged GQA decode attention of BF16 queries over an NVFP4 paged KV cache, with Hq 24 / Hkv 2 / D 256, 2051 selected tokens per row in 64-token tiles, page 16, and NHD and HND KV layouts. The kernel has seven programs: the mma.sync K-first decode, its whole-tile build, the mma.sync cooperative decode that merges its splits in the launch (the fused form), the tcgen05 decode, the tcgen05 cooperative decode, the tcgen05 persistent walk and the split-KV merge. A call takes either the split form (decode + merge) or the fused form (cooperative decode alone). This PR delivers the whole-tile decode for SM120 (compute capability 12.0). It issues every copy of a 64-token tile before that tile's compute, keeps two stages in flight and applies an L2 evict-first policy to the copies. On SM120, the host now selects it for split-form calls whose CTAs each walk at least 11 tiles (704 selected tokens). That covers rows 32 / 64 / 128 at 3 / 2 / 1 splits. Shorter streams keep the fused cooperative decode within the co-resident capacity, as before.
