## 📌 Description

Add experimental NVFP4 attention on SM103 through
`flashinfer.prefill.prepare_nvfp4_attention(q, k, v, out, backend="cake")`.
Preparation quantizes contiguous BF16 Q/K/V once and returns an
`NVFP4AttentionRunner`. Calling the runner executes QK, softmax and PV attention
and writes into the caller's BF16 output without CUDA allocation. Prepare a
new runner when input values or bindings change. The initial backend supports
noncausal attention with D=128 and S divisible by 512.

The API emits the standard experimental warning and hands off to the feature
package. Preparation bounds E4M3 block scales to their finite range before
conversion, including on PyTorch versions that do not saturate finite overflow.
Preparation, JIT registration, and generated CUDA are contained under
`flashinfer/experimental/nvfp4_attention/`.
