## 📌 Description

Add native head dimension 192 to PrimTS context, paged decode, and QToken-KvBlock-Sparse-Attention, including BF16 and pure FP8 Q/K/V. Public tensors keep their logical 192 channels. The staged Keeps path retains 128-wide shared-memory buffers and issues PV N128 + N64 into 192 output columns; Swaps retains padded internal PV staging with bounded output stores.

- Extend fixed multi-query paged decode selection to supported page sizes and sliding windows. Score window candidates using the visible KV union, including partial query groups; windowed split-KV remains disabled.
- Add `count_current_block_in_topk=False` to reserve the current block outside the sparse top-k budget, including when its last token completes the block. The default preserves existing semantics. Workspace sizing and planning must use the same setting.
- Accept strided logical HND cache views in paged prefill, including NHD physical storage and interleaved K/V slices.
- Bound paged sliding-window K/V loads to visible pages. Evicted pages may be recycled under another storage type; their NaNs must not enter PV through zero attention probabilities.
