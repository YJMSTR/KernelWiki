## Kimi-K3 NVFP4 SiTU experts: SM100 16384-token row with per-CTA privatized routing

On SM100 (B200) the 16384-token row now runs `large_q8i_p1024`: the eight stages of the `large_q8i` route that #6341 introduced for the SM100 large rows (tile-128 FC1, the FC2 that stores a signed INT8 partial with one FP32 scale per 128×128 tile, the stream-ordered finalize), with the routing histogram and the routing scatter replaced by two kernels that handle 1024 routed (token, expert-slot) pairs per CTA. The route therefore launches 256 CTAs for the 262,144 pairs of the row where the production routing kernels launch 1024 CTAs of one pair per thread.
