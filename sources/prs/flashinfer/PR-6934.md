## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Cake's StepFun SwiGLU fused MoE (hidden 4096, intermediate 1536, 64 experts, top-k 8) comes in five data-type variants: bf16, fp8 (e4m3), mxfp8, nvfp4 and per-token NVFP4 (`nvfp4_bf16tok`). It is built from 111 kernels per architecture. This PR regenerates all five families. The BF16 FC1 tile-128 kernel now rasterizes its tiles in pairs, and the per-token NVFP4 FC2 tile-256 kernel is now a two-CTA kernel that replaces the one-CTA kernel. The baseline is the previous Cake version of this kernel, which is the package on FlashInfer main from #6801 and #6871. Both versions were measured with whole-graph CUDA-graph replay, on the same node and GPU, in interleaved pairs. Overall performance is unchanged. The only consistent gain is the per-token NVFP4 family at 1024–2048 tokens (about 2–3 %). Everything else is within about ±0.5 % on GB300, except nvfp4 at 8 tokens (1.012x–1.015x). On B200, the large-token bf16, fp8 and mxfp8 rows move in both directions (0.995x–1.011x). Latencies are whole-graph medians in µs. Speedup = previous / this PR, the median over the interleaved pairs, so >1.000x means this PR is faster. Shapes: 5 families × tokens {8, 64, 512, 1024, 2048} × limit {7, 16} = 50
