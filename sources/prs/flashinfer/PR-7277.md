## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`flashinfer.sampling.softmax` on Blackwell (`cake_blackwell_softmax`) has one data type (FP32) and one layout (row-major `[rows, vocab]`). It can fuse a scalar or per-row temperature, and it can use PDL on sm_103a. It is served by 12 Cake programs: a warp program, a rowwise program, a bootstrap program, 7 row-caching cluster programs (1- to 16-CTA clusters x 4 or 8 tiles) and 2 new persistent programs (8- and 16-CTA clusters, 8 tiles). This PR delivers the cluster programs. It regenerates the row-caching programs with a push max/sum exchange and per-tile exponentiation. It adds the persistent route for 8-tile row counts that reach 2.5x the GPU's resident clusters. It also moves the rows the rowwise program and the sm_103a 32K-vocabulary program used to serve to the cluster family, and removes the 32K program. Compared with the previous Cake version in FlashInfer main (`5e4555094c32`), the geometric-mean speedup across the 41 shapes below is 1.283x on B200 (min 1.071x) and 1.263x on GB300 (min 1.060x). Every shape is faster on both GPUs.

Latency in microseconds (median, cold L2), previous Cake version (main `5e4555094c32`) vs this PR, on B200 (sm_100a) and GB300 (sm_103a); CUDA 13.
