## 📌 Description

<!-- What does this PR do? Briefly describe the changes and why they’re needed. -->

Kernel optimizations and performance bring-up of the PrimTS dense context FMHA for **QKV-BF16** at D=128 to parity with existing backends, namely trtllm-gen and cuDNN. Ports some kernel optimizations over from these backends.

Most of the changes below either reorder or skip work. The two error-affecting ones (lazy correction, exp2 offload) match cuDNN settings and stay within cuDNN error against fp32 reference.

**Cumulative changes are described here as well as the tables below:**
- **(pv-overlap) PV overlapped with softmax by publishing P in two 64-key halves (PV-BF16)**: the MMA warp starts PV on keys 0 to 63 while softmax finishes 64 to 127. This alleviates the softmax bottleneck on B200.
MUFU: [softmax N 0:63][softmax N 64:127][corr exp(m_old-m_new)]
MMA:                      [PV N 0:63] [QK N+1] [PV N 64:127]

- **(lazy-correction) Lazy correction (PV-BF16)**: the running row max is frozen unless it grows by more than 2^8 (threshold 8 matching the cuDNN and FlashAttention 4 setting), so the O rescale is skipped on almost every tile
