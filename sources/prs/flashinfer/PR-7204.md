## 📌 Description

Extend the opt-in Frost low-latency backend with an Ampere SM80 projection using CUTLASS cp.async and warp MMA, and broaden the existing Hopper/SM120 grouped paths to qualified FP16 and activation combinations. The runtime discovers matching expert routes from live inputs and shares original weights, typed intermediates, activation lowering and ordered FP32 combine with the existing implementation.

| Architecture | Grouped candidate coverage |
|---|---|
| SM80 | BF16/FP16 default SwiGLU and ReLU2, H2048/I512/top-k10, T4/T8; additionally BF16 default SwiGLU, H7168/I2048/top-k8, T4/T8 |
| SM90 | BF16/FP16 default SwiGLU and GeGLU at T4/T8; ReLU2/SiLU at T8; H2048/I512/top-k10 |
| SM120 | BF16/FP16 default SwiGLU, GeGLU, ReLU2 and SiLU at T4/T8; H2048/I512/top-k10 |

Grouped candidates require matching input/weight/output dtypes and finalized output. SM80 also gains the existing BF16/FP16 FMA path; quantized formats remain unsupported there. All 16 FMA choices and the untuned FMA default remain. The backend remains opt-in; callers set `FrostLowLatencyConfig(max_num_tokens=8)` and tune representative routes/cache conditions.
