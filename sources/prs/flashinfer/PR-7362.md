## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This Cake attention kernel comes in three variants. All three do dense non-causal MHA with D = 128, take BF16 in and give BF16 out, use FP32 softmax and accept any strides (NHD or HND views). Each variant is one call that runs a chain of statistics, quantization and attention kernels, and it smooths and quantizes the inputs on the GPU on every call. The variants are NVFP4 QK + NVFP4 PV on SM100 / SM103 (four kernels), INT8 QK + NVFP4 PV on SM120 (three kernels) and INT8 QK + FP8 E4M3 PV on SM90 (four kernels). This PR delivers the first two as `flashinfer/experimental/nvfp4_attention` (sm_100a, sm_103a, sm_120a), replacing the previously shipped program of that package (SM103 only, `S` divisible by 512, inputs quantized on the host) behind the same call, through `flashinfer.prefill.prepare_nvfp4_attention(q, k, v, out, backend="cake")` and `nvfp4_attention_workspace_bytes`. We measured the complete BF16-in / BF16-out call (statistics + quantization + attention under CUDA-graph replay) against the baseline's complete call.
