## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
FlashInfer's Cake grouped FP8 GEMM family has four forms. Two are contiguous: one uses FP32 scales and the other packed UE8M0 scales (block-scaled MMA). One fuses gate/up with SwiGLU and FP8 re-quantisation. One is masked batched. This PR delivers the masked batched form. It updates the masked batch variant's kernels and routing. The baseline is the previous Cake version of this kernel on FlashInfer main. Across 164 shapes, the PR is faster on 51 (B200), 54 (GB300 #1) and 51 (GB300 #2). It is slower on none. On the remaining shapes, it either runs the same programs and grids as main or ties within run-to-run spread. The largest gains are on the N=512, K=128 shapes, where PR/main latency is between 0.2804 and 0.8869.

B200: NVIDIA B200 (sm_100a), driver 580.82.07, CUDA 13.4; GB300 #1: NVIDIA GB300 (sm_103a), driver 580.167.08, CUDA 13.4; GB300 #2: NVIDIA GB300 (sm_103a), driver 580.159.03, CUDA 13.4; PyTorch 2.14.1+cu130.
