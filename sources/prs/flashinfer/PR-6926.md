## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR updates the Cake export of the FlashInfer `deepgemm_dense_mqa` family. These are the DeepSeek-V3.2 lightning-indexer logits kernels: dense FP8 `fp8_mqa_logits` (32 and 64 heads), dense FP4 `prepare_dense_mqa_logits("fp4", ...)` (32 heads) and paged `fp8_paged_mqa_logits`. All of them use FP32 accumulation and produce FP32 logits. The PR changes two variants. First, the FP4 dense single-launch routes gain a first-tile L2 prefetch form, including a new `fp4:qle1024:short` route for Q ≤ 1024. Second, the 64-head FP8 dense family gains tile-schedule-words routes (`fp8:h64:full:ts`, `fp8:h64:partial:ts`) for the Q = 1023 / 1024, prefix-0 class. The catalog moves from `dense_mqa.v11` to `dense_mqa.v12`, with 73 → 79 generated programs and 38 → 41 dense routes. The 34 paged routes are unchanged and omitted from the tables. The baseline is the previous Cake export of this family on FlashInfer `main` (8dc1163fbfbe). The FP4 first-tile prefetch form is enabled per architecture, so the rows that run changed kernel source differ between the two GPUs.
