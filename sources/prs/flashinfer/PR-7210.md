## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`flashinfer.experimental.cake_mxfp8_megamoe_ep16` (`CakeMxfp8MegaMoeEp16`) runs expert-parallel MoE across 16 ranks. It supports one data-type configuration: BF16 activations, MXFP8 expert weights (E4M3 values with E8M0 scales per 32 elements) and BF16 output. The shape is hidden 3072, intermediate 5120, 512 experts (32 per rank) and top-8. Each forward runs two kernels: a fused kernel for dispatch, FC1, SwiGLU, FC2 and return, followed by a top-k reduce kernel. The module has two backends, CUDA and CuTe DSL. The CUDA backend's fused kernel has two return-protocol forms: a CTA-0 coordinator for 16 and 64 tokens per rank, and an all-CTA protocol for 32 tokens per rank. Both forms are compiled for sm_100a and sm_103a. This PR updates the CUDA fused kernel in both forms on both architectures: the per-K-step publication of the converted weight tile now releases at CTA scope instead of cluster scope, which removes a GPU-wide memory barrier from every K step, and the weight/scale and activation shared-memory rings go from 4 and 2 stages to 8 and 6, with bitwise-identical outputs. End-to-end forward is 1.93x to 2.02x faster than the previous Cake CUDA backend on main.
