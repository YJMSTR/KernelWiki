## 📌 Description

**Depends on #6833** (stacked on its head `ba7cf1920`); this PR will be rebased onto `main` once #6833 lands, leaving only the last commit.

SM107 has more shared memory per CTA than SM100/SM103. This PR lets the BF16 cluster split-K kernel (`dense_bf16_gemm_sm100_splitk.py`, the `cute-dsl` backend of `mm_bf16` for M <= 32) use it and adds a cluster-K split of 8 there:

- `_arch(device)` returns the CuTeDSL arch whose per-CTA SMEM the device provides (`"sm_107"` on SM107, else `"sm_100"`). - `autotune_tactics` enumerates `split_k=8` on SM107 only, where it was measured; `validate_tactic` accepts it on any arch (cluster size 8 is portable).
- `_MAX_AB_STAGES` 12 -> 18. On SM100/SM103 the SMEM capacity still caps every tactic at 12 stages, so their tactic space is unchanged.
