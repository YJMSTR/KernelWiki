## Summary

This PR is the round-2 deslop of two Cake MLA decode families for SM100 / SM103, tracked in #6673. The families are `cake_mla_varq_dcp_decode`, an MLA decode with variable-length queries and decode context parallelism (DCP), and `nvfp4_mla_decode`, the NVFP4 MLA decode. Commit 1 folds the eight DCP main-kernel sources into four. Commit 2 keeps one DCP host binding per query dtype. Commit 3 drops the dead fallback arms and RTC scaffolds from the surviving kernel sources of both families. Commit 4 drops two registry constants that nothing reads. The re-pointed DCP records build from the kept files under per-source compile definitions, and every former kernel symbol stays defined for its program. The PR deletes 10 files: 4 kernel sources and 6 bindings. These do not change: kernel symbols, device code, module names, routes, argument plans, launch parameters, message texts, the public entry points and the two test files.
