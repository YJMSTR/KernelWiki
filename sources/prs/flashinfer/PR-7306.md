## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`cake_nvfp4_mla_decode` (`flashinfer.mla.prepare_nvfp4_batch_decode_with_kv_cache_mla`, experimental) has one variant. That variant is MLA decode with NVFP4 queries and KV cache: E2M1 values with UE4M3 block-16 scales, one 512-wide latent row per token used as both K and V, 64-token pages, an optional per-head attention sink, BF16 output and FP32 LSE. A persistent decode kernel and a split-KV combine kernel serve it.

This PR replaces that variant's programs with faster builds of the same kernel. The baseline is the previous Cake version of this kernel, as currently shipped in `main`. Speedup is 1.046x to 1.124x on GB300 and 1.029x to 1.074x on B200.

Each value is the median latency of one complete call (decode, plus the combine when a request is split), measured with a cold L2. Speedup is the `main` latency divided by this PR's latency.
