## Summary

Regenerates the Blackwell TRT-LLM-style MLA decode backend (`backend="cake"` of `trtllm_batch_decode_with_kv_cache_mla`) from its source programs and replaces the per-architecture, per-SM-count module trees with a small registry, one compiled selector per (domain, architecture) and a thin host module.

- **16 device sources + 20 selector bindings** replace **22 device sources + 16 host modules** split by exact target (`sm_100a/148 SMs`, `sm_103a/152 SMs`): `csrc/cake_trtllm_mla_blackwell` goes from 89,819 to 22,534 lines (78 files changed, +9,675 / −69,570).
- Runtime-shape programs are **one source for both architectures**: the value-split BF16 producer (quarter and half specialisations), the persistent CLC BF16 program, both generic tails, the FP8 page-64 reducer. Only the programs whose traced schedules differ per architecture keep two sources (the FP8 page-64 producer and the two exact-geometry CLC programs below).
