## 📌 Description

Performance and structure work on the PrimTS block-sparse decode kernel (`BlockSparseTSWrapper`, `BlockSparsePagedTSWrapper` and the dense PrimTS path they share) for Blackwell Ultra (SM103), with the 8-bit Sage recipe as the main target. SM100 and SM103 run the same kernel code: architecture-dependent choices are configuration values the planners take from the launch device, not separate code paths. Each commit carries one mechanism with its own measurements and verification; the summary below is the map.

**Features**

- `softmax_rescale_threshold_log2` on the block-sparse plans and one-shot functions (0 to 8, default 8). A row keeps its softmax anchor while a tile raises its maximum by at most that many binades, and FP8 P is quantized at `448 * 2**-threshold` so every probability stays within E4M3; 0 restores exact anchors. The dense decode API is unchanged.
