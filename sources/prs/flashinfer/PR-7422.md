## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR delivers a faster version of the Cake Kimi-K3 vision tower (`kimi_k3_vision_tower`). The package runs the whole tower: the MoonViT-3D encoder (27 layers) followed by the PatchMergerV2 merge. The kernel comes in one data type (BF16 activations and weights, FP32 accumulation) and one layout (packed variable-length token sequences for images, document pages, batches and video frames). This PR delivers a faster version of that variant on sm_100a and sm_103a. The table compares it with the previous Cake version of this package as shipped on FlashInfer main `5e4555094c`. Every shape is faster on both GPUs: 1.011x to 1.074x on B200 and 1.007x to 1.058x on B300.
