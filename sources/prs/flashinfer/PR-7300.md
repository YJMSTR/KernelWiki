## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR speeds up the BF16 rank-major expert-parallel (EP8) layer of the `MoEEpLayer` mega backend for SM100 (`flashinfer/moe_ep/kernel_src/blackwell_bf16_rank_major/`). Cake generates this layer. It uses BF16 activations, weights and output, with hidden size 7168, intermediate size 2048, 256 experts (32 per rank), top-8 routing, 8 ranks and 1 to 128 tokens per rank. The layer has one variant (BF16, rank-major, sm_100a). Like the previous update, this PR changes only the stages around the GEMMs; FC1 and FC2 are unchanged. The three input staging copies now run as one kernel. The input and partial barriers become one-warp arrive kernels that release a per-peer mailbox. Dispatch and combine wait only for the peers they read, so combine pulls each owner's rows as soon as that owner arrives. For up to 16 tokens per rank, dispatch computes the routing itself and the separate route kernel is skipped. The layer now launches nine kernels. The baseline is the previous Cake version on current FlashInfer main, which already includes the earlier non-GEMM update.
