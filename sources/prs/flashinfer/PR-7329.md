## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`flashinfer/experimental/cake_rubin_mla_nvfp4_decode` is the Rubin (SM107, `sm_107a`) variant of the Cake NVFP4 MLA paged decode. Cake is NVIDIA's kernel generator. On compute capability 10.7, `flashinfer.mla.cake_mla_nvfp4_paged_decode` routes to this package. It decodes BF16 queries against the paged NVFP4 MLA KV cache (352 B per token) and writes BF16 output. Previously, the mixed decode's PV epilogue wrote its eight 64-dim output rounds through one 4 KB staging tile per correction warp, and before each round it waited for the previous round's bulk tensor store to finish reading that tile. Each correction warp now alternates between two staging tiles, so a round waits only for the store from two rounds back; the shared-memory footprint grows from 323,584 to 332,800 bytes. The arithmetic is unchanged. This PR also adds a second full-decode program with a converter software pipeline in the pair body. In the previous program, each of a tile's eight rounds waited for its loads, its scale and its conversion in turn.
