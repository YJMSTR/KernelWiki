## 📌 Description

Add a Hopper SM90 implementation of causal sliding-window MLA for DOTS3's
1024-dimensional KV latent cache. The public API is independent of SGLang and
uses FlashInfer's normal TVM-FFI, JIT/AOT and autotune infrastructure.

### Motivation and scope

DOTS3 SWA uses a shared latent KV head with QK dimension 1088
(1024 latent + 64 RoPE), value dimension 1024, and a 513-token causal window.
This PR consumes the existing BF16 Page64 cache directly, without expanding it
into per-query-head K/V or converting it into a packed sparse cache.

The existing SM120 `SparseMLASm120Wrapper` supports `DOTS3_SWA` through its
sparse/packed-cache interface. This PR complements that implementation on SM90;
it does not change the SM120 API, cache format, dispatch or kernels, and does
not claim a performance comparison against SM120.
