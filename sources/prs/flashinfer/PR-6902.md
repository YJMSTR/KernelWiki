## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
The Cake backend of `flashinfer.experimental.nvfp4_attention` (`prepare_nvfp4_attention(..., backend="cake")`) has one shipped variant. That variant runs dense attention over NVFP4 Q/K/V with BF16 output on a persistent-tile schedule, and it is non-causal, has no KV tail and is non-groupwise. This PR delivers that variant as a self-contained Cake package. The device code is the same kernel, so performance matches the previous Cake version shipped in FlashInfer (the shared-unit build): the geomean speedup is 0.997x across the 4 FlashInfer test and benchmark shapes. Times are median GPU kernel time measured with CUPTI on a cold L2 cache, over 3 interleaved groups of 128 iterations each. Speedup = previous / new.

### NVIDIA GB300 (sm_103a, compute capability 10.3), CUDA 13.0 runtime, driver 580.167.08 — 4 timed shapes; geomean 0.997x (0.9975)

| shape | previous (µs) | new (µs) | speedup |
|---|---:|---:|---:|
| b4_h8_s4096 (B=4, H=8, S=4096) | 114.177 | 114.161 | 1.000x |
| b1_h8_s32768 (B=1, H=8, S=32768) | 1435.620 | 1441.845 | 0.996x |
| b8_h32_s8192 (B=8, H=32, S=8192) | 2829.385 | 2837.625 | 0.997x |
| bench_b8_h32_s8192 (B=8, H=32, S=8192, benchmark shape) | 2829.130 | 2837.43
