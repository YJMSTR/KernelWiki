## 📌 Description

Non-contiguous top-k Sage attention with `seqlen_k=4000`, `block_sizes=None`, and per-row block counts fails because the six exported modules omit specialization `(1, 0, 0, 0, 0)` in `(HAS_BLOCK_NUMS, BLOCK_SIZES_MODE, FULL_K64_TILES, UNIFORM_NONEMPTY, CONTIGUOUS_BLOCK_INDICES)` order.

Add that seventh specialization so the existing kernel can serve a partial final KV tile through the default non-contiguous path. Add numerical regressions for `Sq=Sk=4000` and `Sq=128, Sk=4033`, and document that the uniform-count and contiguous-index flags are caller-provided guarantees. Sorted top-k indices with gaps must keep `contiguous_block_indices=False`.
