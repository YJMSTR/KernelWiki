## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
The Cake masked batched FP8 GEMM (`flashinfer.gemm.batch_deepgemm_fp8_nt_groupwise(..., backend="cake")`) multiplies FP8 E4M3 A [B, M, K] by B [B, N, K] with a per-group `masked_m`, FP32 accumulation and BF16 output. It has two scale formats and six kernel forms. FP32 scales use a masked BLOCK_N GEMM, a swap-AB BLOCK_M GEMM, an N=512 / K=128 static-K GEMM or a two-CTA large-N/K GEMM. Packed UE8M0 scales use a swap-AB M224 GEMM or an M32 serving GEMM. This PR delivers 13 new builds of the FP32-scale masked BLOCK_N GEMM and one new build of the two-CTA large-N/K GEMM. It regenerates the swap-AB BLOCK_M, M224 and M32 serving programs with no timing change, except the BLOCK_M 192 program, which keeps main's bytes. The N=512 / K=128 programs are unchanged. The baseline is FlashInfer main's shipped Cake programs, the previous Cake version of this kernel.

Latency per call in microseconds, the median over runs. Speedup = FlashInfer main / this PR, the median of the paired per-run ratios (both pair orders), so it can differ slightly from the ratio of the two medians.
