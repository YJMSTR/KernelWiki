## Summary

This PR cleans up the Cake-generated Sage FP8 block-sparse attention kernels in `csrc/cake_sage_block_sparse_attention/`. It removes five degenerate modules, kernel branches that are never compiled, unused device helpers and copied argument checks. It also folds the 20 SM120 kernel sources into one shared source. The family covers two entry points:
- the SM120 backend of the public `bsa_attn_sm120_blk64_sage_fwd`, where `backend="cake"` is the default (dispatch in `flashinfer/cute_dsl/sparse/bsa_attn_sm120.py`);
- the opt-in SM100/SM103 attention kernel and fused FP8 quantizer behind `bsa_attn_sm100_blk64_fwd(backend="cake")` and `sage_fp8_quantize_sm100`.

The family is JIT only. Every module is built for exactly one target: sm_120a, sm_100a or sm_103a. The diff is 37 files, +478 / -61,360: 24 kernel sources deleted, 1 test file added and 12 files modified.
