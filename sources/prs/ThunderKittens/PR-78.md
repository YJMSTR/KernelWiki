# Main
Replace recursive macros with template, auto and [parameter pack](https://en.cppreference.com/w/cpp/language/pack).
This also resolves the conditional compilation problem for me -- if `globals_struct` is not a template argument, the compiler will throw an error `class "globals" has no member "dynamic_shared_memory"`
even if the member access is guarded by `if constexpr (kittens::py::has_dynamic_shared_memory<globals_struct>)`.
(I wonder how https://github.com/HazyResearch/ThunderKittens/commit/bd21af61b16bdc8d3591e554f865410b3ec9e178 compiles)
This also introduces a stricter check against arguments (the number of arguments can't be more than the actually needed number), see https://x.com/YouJiacheng/status/1874606066996281395

# Minor
