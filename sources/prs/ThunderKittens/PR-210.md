## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Adds two reduced-precision-output GEMMs for SM107: FP8 x FP8 -> FP8 and NVFP4 x NVFP4 -> NVFP4.

Also adds the lane-row tensor-memory loads the epilogues need (`load_async` and `load_async_max_abs` into a register vector), with tests, and cleans up the plumbing in the existing NVFP4-to-BF16 and FP8 GEMMs.
<!-- upstream-excerpt-end -->
