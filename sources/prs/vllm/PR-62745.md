## Overview

Two small mHC TileLang changes in `vllm/model_executor/kernels/mhc/tilelang_kernels.py` that speed up low-batch decode for GLM-5.3-Flash (hidden 4096, hc_mult 4):

1. `mhc_pre_big_fuse_with_norm_tilelang` skips the remaining Sinkhorn iterations when a row's RMS is non-finite. Output is bit-exact. CUDA-graph padding rows reach this kernel as NaN; the root cause is below.
2. `mhc_fused_post_pre_split_config` uses a single-pass config (tile_n 2, 16 splits, 256 threads) for <= 4 tokens when `hidden_size == 4096`. on CUDA devices with compute capability >= 10.0 (where it was tuned). SM90, older GPUs and the ROCm TileLang fallback keep the existing configs.

Related: #61461 tunes the same function for SM90 (H20). This PR targets hidden 4096 on Blackwell and SM107; both changes speed up both. The numbers below are for Blackwell (GB300, RTX PRO 6000).
