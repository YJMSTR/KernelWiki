## Purpose

This PR supersedes #47665, which adds FP8 index-cache support to the
Triton indexer for non-SM100 platforms. It preserves the original commits
and authorship from that PR while adding a fix for the test failures that
were blocking it from being merged.

The original implementation unconditionally cast the indexer input to
`bfloat16` before the dot product. This can reduce accuracy when the
indexer input is `float32` and caused accuracy-related CI failures. This
PR updates the casting logic so that `float32` inputs retain their original
precision while preserving the required behavior for FP8 inputs.
