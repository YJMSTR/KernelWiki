## Purpose

Serve the sparse MSA attention path with `--kv-cache-dtype nvfp4` on SM100, using the existing `fmha_sm100` kernels.

Builds on vllm-project/MSA#19 (merged), which makes per-head K/V slots the NVFP4 cache layout `fmha_sm100` reads.

- **MSA pin:** `vllm-project/MSA` `f355c37` → `be4a52a` (`dev`, the merge of vllm-project/MSA#19). Its CUTLASS decode and CuTe CSR (KV-outer) prefill read the NVFP4 pages in place, and `fmha_sm100` accepts them only as per-head K/V slots.
  - Moving to `dev` also brings in the public MSA #14–#18: Q8KV4/Q8KV8 indexers, a Q8KV4 NVFP4 decode kernel, and a Rubin prefill optimization.
  - `nvfp4_kv.py`, `q8kv4_decode_adapter.py` and `decode_q8kv4/` are added to the install rules. `kvouter/` is installed only because `fmha_sm100/sparse.py` imports it at module load. Of these, only `nvfp4_kv.py` is used.
- **Page layout:** a new NVFP4 subclass of the MSA sparse backend publishes `2·Hkv` head slots × 72 B per token and pins the HND (`LBHNC`) layout.
  - Slot `2·head + side` (K = 0, V = 1) holds that head's packed E2M1 data `[128, 64]`, then its E4M3 block scales `[128, 8]`.
