## Overview

Speed up FP8 per-token-group quantization by computing the per-group scale reciprocal once and multiplying, instead of dividing per element. This covers both CUDA group-quant kernels: `per_token_group_quant_8bit` (smem and register-resident schedules) and the fused RMSNorm+group-quant kernel (`layernorm_utils.cuh`), so that all CUDA fp8 group-quant paths share the same reciprocal-multiply numerics. ~1.2-1.3x kernel speedup on GB300 across M=1..32768; ~1-2% e2e TPOT improvement on Qwen3.5-397B-A17B-FP8 (TP4).

## Claims

- 1.15-1.29x faster `per_token_group_fp8_quant` CUDA kernel on GB300 across M=1..32768 (details below).
- All CUDA fp8 group-quant paths (unfused kernel, fused RMSNorm+quant kernel, Triton fallback, UE8M0 path) now use the same reciprocal-multiply numerics; previously the fused and unfused kernels could disagree by 1 fp8 ulp on ~0.05% of elements.
- ~0.6-2.0% e2e TPOT improvement on Qwen3.5-397B-A17B-FP8, TP4, 8k input / 1k output, at concurrency 1-64.
- Accuracy-neutral: GSM8K / GPQA-Diamond deltas within noise (details below).
