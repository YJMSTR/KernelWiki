**Only difference compared to #62475:** one line in `CMakeLists.txt`, adding `--offload-compress` to `VLLM_ROCM_EXT_FLAGS`.

**Toolchain scope:** `--offload-compress` exists since clang 18 (LLVM PR #67162, 2023-10: https://github.com/llvm/llvm-project/pull/67162). I only tested it with **ROCm 7.2.0 and 7.2.3 (clang 22)** and **ROCm 10.0.0 (clang 23)**; ROCm 6.x was not tested.

## Overview

`csrc/rocm/attention.cu` is a single 3.9k-line translation unit whose kernel instantiation is the tail of the ROCm build: ~9 min of a ~10.5 min build, on one core. This inflation was probably especially caused by recent: #42755  (adds `USE_INTERLEAVED_V_CACHE` as a template parameter to all 12 kernels = interleaved + non-interleaved instantiation (+50%))
