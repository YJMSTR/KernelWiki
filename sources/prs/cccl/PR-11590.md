## Description

Part of #9875 (the `DeviceMemcpy` row).

Replaces the trailing `cudaStream_t` parameter of the two-phase `DeviceMemcpy::Batched` overload with an execution environment (`const EnvT& env = {}`). The overload now goes through `detail::dispatch_with_env_and_tuning` with user-provided storage, so it honors `cuda::get_stream` and `cuda::execution::tune` the same way the single-phase overload does. This mirrors the merged `DeviceCopy::Batched` refactor (#9416) line by line, and follows #11587 and #11589 for `DeviceMergeSort` and `DeviceMerge`.

Existing callers keep working: a `cudaStream_t`, `nullptr` or literal `0` passed in the last position is accepted (`cuda::get_stream` handles the first two, the third falls back to the default stream as before). No caller outside the CUB tests uses `DeviceMemcpy::Batched` in this repository.

The doxygen block of the two-phase overload now documents `EnvT` and `env` instead of `stream`.
