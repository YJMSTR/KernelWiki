## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Renames the warpspeed scan phase `phaseInOutW` to `phaseInOutL` (and the local `refInOutW` to `refInOutL`).

The `L` stands for the **load** phase: the phase in which the tile is loaded into shared memory. This is consistent with `phaseInOutS`, where `S` stands for the **store** phase. The remaining phase, `phaseInOutRW`, is the read-write phase in between and keeps its name.
