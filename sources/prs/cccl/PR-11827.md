## Description

**Context**: discussed with @davebayer how to optimize `WarpReduce` for floating-point types. Before that, we need to provide a fast Min/Max warp reduction for large integers.

In a similar way of

- https://github.com/NVIDIA/cccl/pull/11623

The PR implements a fast warp Min/Max reduction for 64-bit, 128-bit integers based on `warp.redux`. The new implementation replaces 10 shuffle instructions for 64-bit integers and 20 for 128-bit integers with 2 and 4 `warp.redux` respectively.

This leads to **4x** speedup for `I64` and **20x** for `I128`.
