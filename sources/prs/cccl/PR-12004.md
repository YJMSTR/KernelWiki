## Description

In https://github.com/NVIDIA/cccl/pull/11974, I wrongly disabled HW warp redux for FP32 min/max on SM100f.

I reran the benchmarks on two different GPUs (B200, B300) with different clock settings. The results clearly show that FP32 warp redux is faster than the integer path. I'm not sure how the previous (wrong) conclusion came from, e.g. wrong compilation flags, swapped benchmarks, etc.
