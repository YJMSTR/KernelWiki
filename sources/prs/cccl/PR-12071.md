## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Since #9181, `CCCL_AVOID_SORT_UNROLL` was only consulted by the default of `MergeSortPolicy::unroll`. `BlockMergeSort`, `WarpMergeSort`, `StableOddEvenSort`, `SerialMerge` (and with it `DeviceSegmentedSort`) and `MergePolicy::unroll` defaulted to unrolling regardless of the macro. This reads the macro through a single `detail::sort_unroll_default` constant for all those defaults.

Reported by QA in NVIDIA-dev/cccl_qa_agent_findings#492.
