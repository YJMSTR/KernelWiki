## Description

Fixes https://github.com/NVIDIA-dev/cccl_qa_agent_findings/issues/501

The PR #499 for `cub::DeviceFind::LowerBoundSortedValues` didn't support/test large input, e.g. `int64_t`.
The PR extends the routine to support more than 2^31-1 input size by splitting the size in indices that fit in 32-bit values.
