## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
`cub::ThreadReduce` without a prefix starts the reduction with `input[0]`, which reads out of bounds for zero-length static inputs like `cuda::std::span<T, 0>`, a zero-extent `mdspan` or `cuda::std::array<T, 0>`. Since there is no identity element to return, such inputs are now rejected at compile time, pointing to the overload taking a prefix, which returns the prefix for empty inputs.

Addresses the ThreadReduce instance of https://github.com/NVIDIA-dev/cccl_qa_agent_findings/issues/548.
