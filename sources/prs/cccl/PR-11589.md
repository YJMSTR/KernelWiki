## Description

Part of #9875 (the `DeviceMerge` row).

Replaces the trailing `cudaStream_t` parameter of the two-phase `MergeKeys` and `MergePairs` overloads with an execution environment (`const EnvT& env = {}`). The two-phase overloads now go through `detail::dispatch_with_env_and_tuning` with user-provided storage, so they honor `cuda::get_stream` and `cuda::execution::tune` the same way the single-phase overloads do. This follows the pattern of the merged sibling refactors (#9416, #9455 to #9459, #9463, #9464, #9552 to #9555, #11013) and of #11587 for `DeviceMergeSort`.

The overload sets keep their previous shape, so the existing `enable_if` guards on the single-phase overloads still separate the two families at the one overlapping arity. Existing callers keep working: a `cudaStream_t`, `nullptr` or literal `0` passed in the last position is accepted (`cuda::get_stream` handles the first two, the third falls back to the default stream as before).
