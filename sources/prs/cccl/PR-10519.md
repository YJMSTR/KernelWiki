## Description

<!-- Every PR should have a corresponding issue that describes and motivates the work done in the PR -->
Closes  https://github.com/NVIDIA/cccl/issues/10048
<!-- Provide a standalone description of changes in this PR. -->

Adds tunable input prefetching to `cub::DeviceSelect::Flagged`.
For flagged selection, the input-item prefetch is issued before loading and
processing the flags, allowing flag processing to overlap fetching the input
items.

The change:

- integrates the existing prefetch facility into `AgentSelectIf`;
- propagates the prefetch selection through the DeviceSelect tuning policy;
- exposes prefetch as a DeviceSelect::Flagged benchmark tuning parameter;
- keeps `LoadPrefetch::none` as the default policy;
- adds correctness coverage for the supported prefetch policies.

B200 benchmark results show meaningful speedups for large workloads, while keeping it tunable so the optimal policy can be selected per workload.
