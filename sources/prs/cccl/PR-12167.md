## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Several dispatch functions discarded the `cudaError_t` returned by the launcher's `.doit(...)` and relied on a following `cudaPeekAtLastError()`. That only works with the CUDA runtime launcher; with a non-runtime launcher (e.g. `cuLaunchKernel`) the launch error was lost. The returned error is now propagated, following the existing `CubDebug` pattern.
