## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Every `DispatchXxx::Invoke()` repeated a full

```cpp
#if _CCCL_HOSTED() && defined(CUB_DEBUG_LOG)
    NV_IF_TARGET(NV_IS_HOST, ({
                   ::std::stringstream ss;
                   ss << active_policy;
                   _CubLog("Dispatching DeviceXxx to compute capability %d.%d with tuning: %s\n",
                           cc.major_cap(), cc.minor_cap(), ss.str().c_str());
                 }))
#else
    log_dispatch("DeviceXxx", cc, active_policy);
#endif
```

block just to print the "Dispatching `<Algorithm>` ... with tuning: ..." message.

- Adds `_CUB_LOG_DISPATCH(device_alg, cc, active_policy)` to `cub/detail/logging.cuh`.
- Migrates all 29 call sites across the dispatch layer to the new macro, collapsing each site's boilerplate to a single line.

Also fixes two inconsistencies found while migrating:
- `dispatch_batched_topk.cuh` only logged under `CUB_DEBUG_LOG` and had no `detail::log_dispatch` fallback at all; it now supports both mechanisms like every other dispatcher.
- `dispatch_find_bound_sorted_values.cuh`'s two branches disagreed on message wording ("to arch %d" vs "on compute capability %d.%d"); both now produce the same message.

Co-Authored-By: Claude
