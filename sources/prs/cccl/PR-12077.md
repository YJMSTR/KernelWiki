## Description

Fix https://github.com/NVIDIA-dev/cccl_qa_agent_findings/issues/541

A recent refactor of `pair.h` triggered a regression in `WarpScan`. The reason is that the code uses the user-provided copy constructor (from assignment) instead of relying on the compiler-generated one.

The simplest fix is to use a `const` reference in `WarpScan` instead of pass by-value.
Fingers crossed, the PR should not change the SASS for other routines/types
