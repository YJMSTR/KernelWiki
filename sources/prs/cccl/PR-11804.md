## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
The first warp of the scan-and-store squad also issues the TMA bulk store. That store takes longer than expected, so this warp lags behind the other three, which then wait for it at the squad barriers.

<img width="1069" height="363" alt="image" src="https://github.com/user-attachments/assets/f6ac3ecc-1c5d-4d13-b02e-581f12c95a0c" />

This PR moves the bulk store into a new single-warp store squad. The scan squad now only writes the output tile to shared memory and releases it, and the store squad acquires it and issues the bulk store.
