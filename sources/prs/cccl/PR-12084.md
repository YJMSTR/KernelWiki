## Description

CUDA headers `<cuda_runtime_api.h>`, `<driver_types.h>`, and ` <cuda_runtime.h>` are included by default (pre-include) by all CUDA compilers (nvcc, clang, nvc++).
The only exceptions are NVRTC that has no runtime API and host compilers that use `cuda/std/__cccl/cuda_toolkit.h` (`__cccl/__config` is included everywhere).

The PR explicitly removes them because redundant.
<!-- upstream-excerpt-end -->
