## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Since #9056, `BLOCK_LOAD_VECTORIZE` and `BLOCK_STORE_VECTORIZE` vectorize all contiguous iterators, which broke code that previously fell back to element-wise loads/stores: iterators whose value type differs from the item type, iterators over volatile elements, and (for stores) item types without a default constructor. These cases fall back to the element-wise path again.
