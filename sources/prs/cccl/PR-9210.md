## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR is a port of `cub::DeviceTransform` (#8087, #9038) onto cutile, and to compare side-by-side with the existing CUB benches.

The intention is that we gate all the tile code behind a Macro, so that it is invisible to user when the Macro is disabled (by default). And we can do CI / test performance of cutile with the Macro enabled.

Before the benchmarks, it is important to note that SIMT-Tile interop for TileIR is still work in progress. Thus, right now, the custom function the user passes in must be a `__tile__` function, and it must consist of tile operations and must be inlinable.
