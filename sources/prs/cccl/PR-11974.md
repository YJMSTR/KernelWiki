## Description

The PR is the result of the internal discussion with @davebayer regarding the optimization of `WarpReduce` for floating-point types with `minimum/maximum` operators.

The idea is pretty straightforward: mapping floating-point values to signed integer of the same size, then use `warp.redux`.

Some perf numbers compared to warp shuffle reduction:
