## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Based on an idea from @nanan-nvidia implemented in RLE, let's try to use a single squad for issuing bulk copies and work stealing.

The benefit of using 1 warp less is that the block size shrinks by 32 threads, so there are more registers available per thread. I assume we can now find better configurations during tuning now, but I haven't tried retuning it.
