## Description

Follow-up to #7705, closes #9867.

This PR migrates cuCollections `static_map`'s host and device `find` into cudax `fixed_capacity_map`, mirroring the `insert`/`contains` migration:

- Host `find`/`find_async` + `find_if`/`find_if_async`
- Device ref scalar and CG `find`
- `__find_if_fn`/`__find_if_n` kernels and impl `find_if_async`
- `test_find.cu` and `find.cu` benchmark (ported from cuco)

No existing code paths modified.
