## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Every kernel launch in the dispatch layer logged its configuration via a repeated

```cpp
#ifdef CUB_DEBUG_LOG
    _CubLog("Invoking foo_kernel<<<%d, %d, 0, %lld>>>(), ...\n", grid, block, stream, ...);
#else
    detail::log("Invoking foo_kernel<<<%d, %d, 0, %lld>>>(), ...\n", grid, block, stream, ...);
#endif
```

block, duplicating the format string and argument list between the two branches at ~80 call sites.

- Adds `_CUB_LOG_KERNEL_LAUNCH(kernel_name, grid_dim_x, grid_dim_y, grid_dim_z, block_dim, smem_bytes, stream, fmt, ...)` to `cub/cub/detail/logging.cuh`. `kernel_name` and `fmt` must be string literals (adjacent-concatenated into one format string at compile time).
- Migrates all "Invoking `<kernel>`<<<...>>>" logging call sites across the dispatch layer to the new macro, dropping the now-redundant `items_per_thread` (already covered by the separately-logged tuning policy).

Co-Authored-By: Claude Sonnet 5 <noreply@anthropic.com>
