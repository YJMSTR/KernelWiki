## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR fixes issues when multiple scan kernels are being run at the same time. The idea is to set the smem limit to the highest possible value. That should prevent races between threads trying to set the limit to their kernel's limit.

This PR also fixes how we determine the smem limit. It turns out that `CU_DEVICE_ATTRIBUTE_MAX_SHARED_MEMORY_PER_BLOCK_OPTIN` already accounts for reserved and constant shared memory, so we need to subtract only the statically allocated shared memory.
<!-- upstream-excerpt-end -->
