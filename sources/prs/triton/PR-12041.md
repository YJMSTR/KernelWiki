## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Allow matrix producers to write tiled values and pass them to the ordinary `matmul` API without repacking or a separate launcher. `TiledLayout` describes the storage encoding, the existing TMA builder creates its five-dimensional descriptor, and the persistent kernel loads its tiles directly.

The initial matmul support is limited to aligned, persistent ragged-K TMA operations with one tile along the contiguous dimension. Unsupported descriptor shapes and noncontiguous encoded storage are rejected.

Validation on Blackwell: 28 tests passed, covering exact layout round trips, retained output buffers, either or both tiled operands, BF16/FP32 outputs, accumulation, and an empty slice. The same 28 tests pass with the upstream explicit bias-FMA fix (`0d45e109ad9e7d3dd5bf11b961fd590a2368a160`) included in this branch.
