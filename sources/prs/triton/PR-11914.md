## Summary

Use physical storage width for Tensor Memory Accelerator (TMA) stride alignment. Packed FP4 uses `uint8` storage; using its logical 4-bit width incorrectly rejects a 16-byte row stride. Preserve gathered row indices for activation scales so values and scales use the same source rows.

Without preserving those indices, the H100 pointer-gather path pairs `X[gather[i]]` with `X_scale[i]`, producing numerical mismatches rather than a TMA error (maximum relative error 0.9443 versus 0.02 allowed in one case).

[NVIDIA specifies `globalStrides` in bytes, with 16-byte alignment for ordinary TMA.](https://docs.nvidia.com/cuda/cuda-driver-api/cuda_driver_api/group__CUDA__TENSOR__MEMORY.html)

## Desired features

- Accept packed FP4 tensors whose physical storage strides satisfy ordinary TMA alignment.
- Keep gathered activation values and their block/tensor scales on the same source rows.
