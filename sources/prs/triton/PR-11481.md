## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Remove barriers inserted independently by arrival, wait, MMA, and TMA lowerings.
Insert barriers centrally, sharing one barrier between compatible operations—for example, consecutive arrivals from the same issuer.
Carry ordering requirements through control flow and function calls.
Delay synchronization until a consumer needs it, while handling loops and memory-lifetime markers.
<!-- upstream-excerpt-end -->
