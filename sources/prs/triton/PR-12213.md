## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Allow Blackwell activation scales to use four-column padding when eight-column padding would waste storage. Callers can opt in with `BlackwellActMXScaleLayout(None, column_alignment=4)`; the default remains 8 and the 128×4 swizzle is unchanged. Reject alignments other than 4 or 8, and repack storage when converting between the two alignments.

Add CPU regression tests for the compact layout's storage shape and round trip, plus conversion from 4 to 8 and back. The two new tests and nearby storage-shape, symbolic-shape, ragged-shape, and no-op conversion tests pass: 37 cases, using the local `triton_kernels` code with the installed Triton package. No GPU tests were run.
