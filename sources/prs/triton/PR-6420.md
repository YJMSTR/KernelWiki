## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Add a new flag to pick the packing format for fp4 inputs in dot_scaled op. This allows supporting hardware fp4 transpose in blackwell by going through the mixed mode mxfp4 * mxfp8 message.
Using this path will prevent getting fullt throughput when using dot_scaled mxfp4 * mxfp4.
<!-- upstream-excerpt-end -->
