## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
SM12x targets do not support TCGen05, but TCGen05/TMEM operations could reach lowering and cause an LLVM abort when ConSan inserted a wait.

Reject these operations during NVIDIA GPU IR verification on unsupported targets. Update affected test targets, document the architecture requirement, and add a native MLIR regression.

Fixes #11747.
