## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
We generalise the mmav5 lowering to support this case. When doing this, we also lower commit using a 32b register rather than a 64b, following the docs + the way CUTLASS does it (saves one ptx instruction).

We add a `twoCTADim: Optional[unsigned]` to CTALayout which signals the dimension the first two CTAs should own.
As per usual, the ground truth for the semantics of this flag is in `LinearLayoutConversions.cpp`.

I also took this chance to tighten the verifier of CTALayout and clean-up its associated parsers. We should tighten these even more by making sure layouts have the `twoCTA` part set iff the module is in `two-cta` mode. This would take a bit more care tho.
<!-- upstream-excerpt-end -->
