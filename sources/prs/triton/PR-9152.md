## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
When pipelining wgmma with the left hand argument in registers, we split the dot along the K dimension which allows us to effectively "multi-buffer" the wgmma by having multiple sets of registers which are not used by the wgmma at the same time.

Currently rs dots are split into `K // instrK` dot ops which theoretically maximizes parallelism, but in practice I see that splitting into 2 gives the best performance. This gives ~1% uplift in bf16 x mxfp4 moe.
<!-- upstream-excerpt-end -->
