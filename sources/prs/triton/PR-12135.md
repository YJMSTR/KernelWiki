## Summary

Add Blackwell matmul support for NVIDIA FP4 (NVFP4) activations and microscaled FP4 (MXFP4) weights. Convert activation tiles to microscaled FP8 (MXFP8) inside matmul using FP32 arithmetic, without writing intermediate activations to global memory. This conversion adds rounding error.

This path is currently significantly slower than MXFP8 × MXFP4 matmul. It provides correctness support for NVFP4 activations with MXFP4 weights; performance optimization remains future work.

### Desired features

- Fused NVFP4 → MXFP8 conversion in groups of 32.
- Unswizzled or Blackwell activation-swizzled NVFP4 scales; strided or Blackwell-swizzled MXFP4 weights.
- Plain, batched, ragged, and gathered inputs, including combined ragged/gathered inputs.
- Outer tensor/row scales applied once in the epilogue.
- BF16 output by default, with explicit output dtypes and supplied output tensors supported.
