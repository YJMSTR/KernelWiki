## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Choosing GSan's shadow granularity and `write_once` policy currently requires manual inspection. Add a `gsan-profile` instrumentation mode that records observed accesses and reports granularity and write-once candidates for each tracked storage lifetime.

The profiler uses a dedicated allocator with compact metadata, while sharing allocation and descriptor helpers with GSan. A direct PyTorch CUDAAllocator is installed explicitly before CUDA initialization; profiling is enabled only inside `AllocationProfile`. Storage retirement summarizes and resets metadata in stream order, allowing allocator reuse without retaining tracked tensors. Reports are available after context exit.

Supports multiple CUDA devices, shared IPC/FABRIC mappings, and collective Gloo/NCCL reports. Unmanaged memory and raw allocator clients are ignored. Runtime constants are shared through native bindings, and the device entry points match the current atomic instrumentation ABI, including vectorized atomic element widths.
