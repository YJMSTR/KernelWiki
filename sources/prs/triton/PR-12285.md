## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Apply NVFP4 row scales before MXFP8 quantization in both matmul kernels, matching explicit conversion followed by MXFP8 × MXFP4 matmul. Update shared-memory accounting to exclude the removed row-scale epilogue scratch.

```text
s: outer row scale
x: NVFP4 activations decoded with block scales, before applying s
W: MXFP4 weight matrix
Q: MXFP8 quantization

Before: s * (Q(x) @ W)
After:  Q(s * x) @ W
```

Tested on GB300, including exact parity for fused outputs; reduce the related matmul test matrix from 400 to 200 cases.
<!-- upstream-excerpt-end -->
