## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
As discussed in https://github.com/triton-lang/triton/issues/9433, add dummy `mov` instructions for the register operand to establish the correctly synchronized pattern:

```
// update regs
w1, w2 = ...

mov w1', w1
wgmma w1', x1, acc
commit_group
wait 1

mov w2', w2
wgmma w2', x2, acc
commit_group
wait 1
```
