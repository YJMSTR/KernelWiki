## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Adds event-based intra-kernel profiling for asynchronous operations:

  - Introduces `pl.allocate_event`, `pl.start_event`, and `pl.end_event`.
  - Uses an opaque event type that can cross loops, functions, and warp-specialized regions.
  - Supports NVIDIA and AMD lowering.
  - Adds compiler tests, documentation, and a pipelined TMA/TCGen05 tutorial.

```python
  event = pl.allocate_event("async_copy")

  pl.start_event(event)
  issue_async_copy(...)

  # The matching wait may occur in a later pipeline iteration.
  wait_for_copy(...)
  pl.end_event(event)
```

  This allows Proton to measure asynchronous transactions whose issue and completion do not form a conventional lexical scope.
<!-- upstream-excerpt-end -->
