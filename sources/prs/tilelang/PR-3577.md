## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
The Ascend BF16/FP8 GEMM examples are missing parts of the public [DeepGEMM-Ascend](https://github.com/deepseek-ai/DeepGEMM-Ascend) configuration selection and epilogue API. This updates the heuristic and adds the corresponding output behavior across dense, batched, and grouped GEMMs.

- Share kernel construction, compute, and epilogue handling. Support fused bias, Alpha, BF16 stochastic rounding, FP8 quantization, direct stores, and empty-group initialization without accumulation.
- Port the heuristic's FP4, dequantization, and L1 residency branches. Keep execution limits in `execution_config`, and limit launches to cores that own output tiles.
- Add `T.simd.vst2` frontend validation, intrinsic registration, code generation, and runtime support. Use the dual-source interleaved store in stochastic rounding and cover its lane ordering and invalid inputs.

FP4/dequantization kernels and L1 residency remain unimplemented in the executor, and epilogue stages are capped at eight. These limitations have explicit TODOs; full performance parity remains follow-up work.
