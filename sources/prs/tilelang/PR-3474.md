## Summary

- Remove hard-coded `target="ascend"` values from Ascend examples and tests so they honor `TILELANG_DEFAULT_TARGET`.
- Let DeepGEMM JIT entry points use the target-default execution backend, allowing `execution_backend="auto"` to select the backend for the configured target.
- Run the Ascend examples in CI with both `TILELANG_DEFAULT_TARGET=ascend` and `TILELANG_DEFAULT_TARGET=pto`.
- Document how to select AscendC or PTO through the environment variable.

## CI coverage

The Ascend example suite is invoked once for each target with `TILELANG_EXECUTION_BACKEND=auto`.
