## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Use the CUDA target kind instead of a string-prefix check when selecting the implicit stream in the NVRTC and CuTeDSL adapters. Query the current stream for the first input tensor's device, so non-default streams are selected correctly even when the caller's current GPU differs.

Explicit stream handles remain authoritative. NVRTC calls without a tensor retain the current-device stream. The final diff changes only the two adapters and adds no tests.

Related: #3301 (F149), #3408.

Scope: this PR fixes stream selection. Cross-device default-stream launch contexts remain a separate, unresolved issue; those callers must make the tensor's CUDA device current before launch. There is no per-call Python device guard in this patch.

Validation:
- Existing NVRTC and CuTeDSL test files after guard removal: 9 passed, 1 Hopper-only skip, 2 performance tests deselected.
- `format.sh` and `git diff --check` passed.
- Both adapter sources match the stream-query implementation at c69a3a29, which was checked locally with real Torch streams and GPU launches for same-device and cross-device non-default streams. These checks do not establish correct cross-device default-stream launch contexts.
