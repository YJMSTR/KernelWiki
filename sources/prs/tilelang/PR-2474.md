## Summary

- Remove unsupported legacy `tl_gemm` and `tl_gemm_sp` lowering paths and their CUDA template headers.
- Reduce CUDA template include overhead by splitting heavyweight helpers out of `common.h` and including only the pieces needed by generated kernels.
- Keep generated CUDA for normal tile operations lighter, which cuts NVCC compile time for representative matmul and attention kernels.

## Changes

- Drops obsolete GEMM template headers and codegen paths for `tl_gemm` / `tl_gemm_sp`.
- Moves math helpers into a focused CUDA template header and trims unconditional includes from common CUDA templates.
- Updates CUDA/CuteDSL/ROCm codegen include emission to request only required support headers.
- Adjusts tests and fixtures that referenced the removed legacy tile GEMM path.

## Validation

- `pre-commit run --all-files`
- Local compile-time measurements on `sm_100a`, Debug build with `USE_CUDA=ON`, 5 runs per case:
  - matmul include-split comparison: TileLang compile `5.31s -> 3.90s`, NVCC `2.83s -> 1.43s`.
  - attention include-split comparison: TileLang compile `8.57s -> 7.05s`, NVCC `3.18s -> 1.65s`.
