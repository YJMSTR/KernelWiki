## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR introduces a native TileLang backend for **Huawei Ascend 950 NPUs**. It provides an end-to-end compilation and execution path, including an Ascend language dialect, hardware-specific lowering, automatic scheduling and synchronization, device code generation, Bisheng compilation, and NPU runtime integration. By specifying `target="ascend"`, users can now develop and run high-performance kernels for Ascend 950 NPUs directly in TileLang.

## Ascend Programming Model

See the [Ascend README](<https://github.com/tile-ai/tilelang-deepseek/blob/asc-on-upstream-main/tilelang/ascend/README.md>) for a quick introduction to the new backend’s programming model and examples to get started.
- Add the `tilelang.ascend.language` dialect, with Ascend-specific kernel launch, memory allocation, data movement, and compute operations.
- Compose Cube `T.gemm` (AIC) and Vector computation (AIV) in a single kernel.
