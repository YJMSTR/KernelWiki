## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR adds new 1CTA MLA kernels adapted for dense decode or sparse top-k with <= 64 query heads, and extends recompute P sparse MLA backward to cover heads 1...128 via supporting the TMA padding introduced in #2883. The new 1CTA MLA forward kernel supports fp8 with descale tensors and split-kv, and a follow-up PR adding this functionality for 2CTA MLA is planned. To simplify the merge, interface changes were kept minimal to the greatest extent possible.

Sparse MLA backward for 128 heads also speeds up ~1.5x by adding `-O2` to the compile options, as measured for cutlass dsl 4.7.1 with cu13 libs. See the table on the `-O2` fix below for more comprehensive numbers.

The rest of the PR description is Claude's summary.

## Summary

This PR adds a second SM100 forward kernel for MLA (absorbed: `qv` with hdim_v 512, rope
hdim 64). It runs one 64-row tile per CTA (`tcgen05.mma.ws`) instead of one 128-row tile per
2-CTA cluster. A dispatch heuristic chooses between it and the existing 2CTA kernel.

- **Dense MLA decode.** With split-KV, 1.1-22x faster than the 2CTA kernel (largest at small
  batch and long context). The 2CTA kernel cannot split at hdim_v 512. Large-batch decode
  reache
