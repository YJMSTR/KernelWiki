**Series**
1. Tests first, named 2CTA schedules and TMEM widths (#2964)
2. 64-row KV tile per CTA (M=64 TMEM layout) with GQA, varlen and deterministic support (#2965)
3. **hdim 256 on the general kernel (opt-in)** ← this PR
4. Pack the query heads of a KV head into the Q tile (GQA) (#2967)
5. Make it the default and delete the dedicated kernels (#2968)

**One kernel with 5 GEMMs instead of a dQ / dKdV pair with 7: as fast or faster than the dedicated pair on MHA and varlen, at parity on GQA from 8k** (GQA at 2k is fixed by step 4); hdim 256 gains softcap, learnable_sink, local, deterministic, score_mod, mask_mod and block sparsity.
