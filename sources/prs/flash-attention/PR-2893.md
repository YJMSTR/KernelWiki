## Summary

The softmax warps of the sparse-MLA backward (`flash_bwd_mla_sm100.py`) rounded three intermediates to bf16 before forming `dS = P ⊙ (dP − dPsum) · softmax_scale`: the normalization scale `scale_p`, the normalized `P`, and `(dP − dPsum) · softmax_scale`. This PR keeps an fp32 copy of `P^T` and forms the product in fp32, rounding to bf16 exactly once for the dS store.

- **Load-P path (default):** the saved bf16 `p` is upcast, normalized with the fp32 `scale_p`, and rounded to bf16 once for the `dV += P^T·dO` mma operand; the fp32 copy is used for dS.
- **Recompute-P path (`gather_bwd_recompute_p=True`):** the fp32 `exp2` result already exists; it now stays live for dS instead of being re-read from the bf16 staging copy.
- Unchanged: forward kernel, saved activations, dS storage dtype, all mma operand dtypes, smem layout.
- `AI/SPARSE_MLA_RECOMPUTE_P.md` numerics section updated.

Both backward paths (load-P and recompute-P) get the same treatment so their dS numerics stay on one scheme.
