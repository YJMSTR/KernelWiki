## Problem

With NaN in K or V rows past `seqused_k` — in a padded packed buffer (`cu_seqlens_k`) or in the dense `(b, s, h, d)` layout — the SM100 backward returns an all-NaN `dQ`; `dK`/`dV` stay finite. This is independent of #2983: with a finite `O` and `D` from that forward fix, `dQ` is still all-NaN, so in the dense layout the loss is clean and only the gradient is poisoned.

The backward is KV-stationary and TMA-loads whole K/V tiles. The masked `dS` is exactly zero past the sequence end, but

- `dP = dO @ V^T` reads the V rows → `0 * NaN = NaN` in the masked `dP` columns;
- `dQ = dS @ K` sums over the whole tile → NaN from the poisoned `dS` **or** directly from NaN K rows.

So unlike the forward, a NaN **K** tail is enough on its own.
