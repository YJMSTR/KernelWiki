## Summary
Guard the SM80-derived forward kernel body with `work_tile.is_valid_tile`. SM120 inherits this implementation.

The functional change is a single validity guard; the remaining diff is indentation of the guarded kernel body.

## Root cause
`SingleTileVarlenScheduler` may launch padding tiles with `batch_idx == num_batch`. The forward kernel previously allowed these invalid tiles to construct `SeqlenInfoQK`, causing out-of-bounds reads from `cu_seqlens` and CUDA error 700 on SM120.

## Reproduction
On the unpatched upstream `main`, the following command fails on NVIDIA RTX PRO 6000 Blackwell (SM120):
```bash
CUDA_VISIBLE_DEVICES=0 \
FLASH_ATTENTION_CUTE_DSL_CACHE_ENABLED=1 \
pytest -q -s tests/cute/test_flash_attn_fast.py -x
```

The failure occurs in: `test_flash_attn_varlen_output[128-64-False-mha-dtype0]` with:

```bash
CUDA error: an illegal memory access was encountered
Error code: 700
```

## Validation
Tested on NVIDIA RTX PRO 6000 Blackwell (SM120) with PyTorch 2.11.0+cu130 and CUTLASS DSL 4.6.0.dev0.

After applying the fix:
- The previously failing test case passed in 10 consecutive runs.
- The same full command completed with 192 passed, 48 skipped.
