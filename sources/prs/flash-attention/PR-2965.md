## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
> Stacked on #2964 (merged as 76d93310); rebased onto it, so the diff is now just this PR's two commits.

Adds the accumulator layout the hd256 backward needs to the general kernel, behind a test knob.

**Series**
1. Tests first, named 2CTA schedules and TMEM widths (#2964)
2. **64-row KV tile per CTA (M=64 TMEM layout) with GQA, varlen and deterministic support** ← this PR
3. hdim 256 on the general kernel (opt-in)
4. Pack the query heads of a KV head into the Q tile (GQA)
5. Make it the default and delete the dedicated kernels

**Default configurations compile to byte-identical CUBINs**; the layout is reachable only through `FLASH_ATTENTION_BWD_TILE_N=64` (hdim ≤ 128) until step 3.

**Changes** (`acc_m64`, `NOTE [M=64 accumulator layout]`)

Commit 1 — the 64-row KV tile
- S / dP are read through the layout-aware `tcgen05.make_tmem_copy`; each thread owns one (row, 32-column) chunk.
- P^T and this CTA's dS^T are staged in SMEM as the A operands of the dV / dK MMAs (as the dedicated dKdV kernel does); TMEM no longer holds P / dS.
- The dS exchange half for dQ is chosen by the thread's lane half; the dK / dV TMA epilogue stages the whole tile per CTA.
