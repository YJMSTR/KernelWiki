## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Opens the series that moves the hd256 backward onto `FlashAttentionBackwardSm100`, completing what #2962 did for the forward.

**Series**
1. **Tests first, named 2CTA schedules and TMEM widths** ← this PR
2. 64-row KV tile per CTA (M=64 TMEM layout) with GQA, varlen and deterministic support (#2965)
3. hdim 256 on the general kernel (opt-in) (#2966)
4. Pack the query heads of a KV head into the Q tile (GQA) (#2967)
5. Make it the default and delete the dedicated kernels (#2968)

**No behavior change in this PR**: tests only, plus a refactor that compiles to byte-identical CUBINs.

**Changes**

Commit 1 — tests
- `tests/cute/eager_reference.py`: the FP64 reference helpers, moved verbatim out of `test_hd256_varlen_scheduler.py` so other files can use them.
- `tests/cute/test_flash_attn_hd256_bwd.py` (new, 96 cases): tile edges 127/128/129, a partial last tile, 4096, Q/K mismatch both ways; dense and varlen (with an empty slot); MHA and GQA 24/4; bf16/fp16; causal and not.
- `test_score_mod.py`, `test_mask_mod.py`, `test_flash_attn_race_condition.py`: `d=256` added to the backward matrices; combinations the dedicated kernels do not support skip with the reason.

Commit 2 — preparation
