## Description

Adds the FP4 MLA attention backend, ported from an internal Rubin development
branch. `main` has no equivalent: there is no `fp4_mla` module, rename detection
against the branch finds no same-origin file on `main`, and a capability search
turns up nothing that provides this backend.

The package lands under `tensorrt_llm/_torch/attention/backends/fp4_mla/` with its
entry point alongside the other backends in `.../backends/fmha/`, matching the
current layout on `main` rather than the older layout it came from. Imports were
remapped accordingly:

```
_torch.attention_backend.*             -> _torch.attention.backends.*
_torch.pyexecutor.kv_cache_manager_v2  -> _torch.pyexecutor.kv_cache.kv_cache_manager_v2
```

The change is purely additive: 11 new files, no existing file modified. No module
on `main` imports the new package, and the backend selects itself only when
`get_sm_version() == 107`, so it is inert on every architecture currently covered
by CI. It cannot alter any existing execution path.
