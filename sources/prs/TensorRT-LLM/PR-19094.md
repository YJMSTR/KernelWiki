## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Enable fused DSA decode metadata by default to reduce metadata launch overhead. Replace `TRTLLM_FUSED_DSA_METADATA` with `TRTLLM_DISABLE_FUSED_DSA_METADATA` (unset or `0` enables fusion; any other value disables it), move the Triton kernel into DSA `kernels.py`, and update the tests. Existing eligibility checks and eager fallbacks are preserved.

Default enablement is supported by exact metadata parity tests and GB200 accuracy evaluations of DS-V3.2 and GLM-5.2 NVFP4 on GPQA Diamond, AIME25 and AIME26, showing small aggregate score changes:

| Model | GPQA Diamond | AIME25 | AIME26 |
|---|---|---|---|
| DS-V3.2 | 332 → 331 /396 | 54 → 55 /60 | 58 → 56 /60 |
| GLM-5.2 | 360 → 359 /396 | 55 → 55 /60 | 56 → 55 /60 |

Scores are audited final-answer correctness, fusion off → on, aggregated over two runs per model (198/30/30 unique questions per run).

Validation: 152 exact metadata tests passed on each of GB200 and GB300 in the preceding campaign; related tests had 154 passes and 24 skips. For this change, pre-commit checks and isolated flag checks passed, and the relocated kernel computation is unchanged. GPU tests have not been rerun after relocation.
