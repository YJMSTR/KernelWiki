## Description

Two C++ kernel speedups found on GLM-5.3-Flash, one commit each. The FP8 quantization change is bit-identical to main. The router GEMM change replaces cuBLAS with a kernel that accumulates in a different order, so the 288 x 4096 router logits change at FP32 rounding level.

### 1. Vectorized BF16-to-FP8 1x128 activation quantization

`scale_1x128_kernel` (behind `fp8_quantize_1x128` and the FP8 block-scale GEMM runners) and `scale_1x128_reshape_kernel` (behind `fp8_batched_quantize_1x128_permute102`, the MLA BMM operand) use one warp per 128-wide group, with two 4-byte loads and four 1-byte stores per lane.

This PR adds vectorized variants: 16 lanes own one group, each loads its 8 inputs with one 16-byte load, the group amax is reduced with 4 warp shuffles, and each lane stores its 8 outputs with one 8-byte store. Partial last groups (for example K = 576) are handled in the same kernel. The scale arithmetic, including UE8M0 rounding, is copied unchanged.
