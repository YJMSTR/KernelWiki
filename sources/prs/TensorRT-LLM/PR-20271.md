## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
FP8 CUDA-core GEMM launches `N/2` blocks along grid Y. At `N=131072`, this exceeds CUDA’s grid-Y limit of 65,535 blocks and causes the reported output-head warmup failure on DGX Spark.

Move N to grid X and update the matching device indexing. The launch changes from `(1, 65536)` to `(65536, 1)`.

Add `Kernel.Fp8WideOutput` with `M=8, N=131072, K=16` to check launch success and complete FP8→BF16 output against a CPU reference.

Existing kernel test will already run the code change in CI.

## Dev Engineer Review

The kernel now maps grid X to N tiles and grid Y to M tiles. The device indexing uses the same mapping, so wide outputs avoid exceeding CUDA’s grid-Y limit without changing the output layout. The change is limited to launch geometry and its matching indexing.
