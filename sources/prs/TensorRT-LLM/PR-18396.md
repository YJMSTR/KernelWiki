## Description

This PR improves FLUX.1-dev static-NVFP4 execution in TensorRT-LLM VisualGen on Blackwell:

- Adds CuTeDSL to the default NVFP4 GEMM candidate set, so autotuning considers it alongside CUTLASS, cuBLASLt, and CUDA Core.
- Shares compatible static-NVFP4 activation quantization between the single-stream MLP and QKV projections after checkpoint loading.
- Enables CUTEDSL NVFP4 GEMM+GELU fusion for FLUX dual- and single-stream MLPs on SM100/SM103 when the NVFP4 input scale is statically calibrated. Dynamically quantized FLUX NVFP4 keeps the unfused path, which still runs GELU eagerly (compiler-disabled).
- Leaves GELU fusion eligibility unchanged for every other model: their MLPs still fuse with any NVFP4 activation quantization, including dynamic quantization (for example, Wan and QwenImage).
- Adds CUTEDSL attention support for statically calibrated, per-tensor E4M3 Q/K/V (`qk_dtype: fp8`, `v_dtype: fp8`, and Q/K/V block sizes `0`) using ModelOpt checkpoint `amax` values.
- Extends the fused DiT Q/K RMSNorm+RoPE CUDA op to directly emit scaled E4M3 Q/K/V, removing the three standalone attention-quantization launches.
