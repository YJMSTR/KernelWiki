## Description
  This PR adds optional mixed-precision KV caching using native KVCM V2 pools, retaining first/last tokens at the configured KV dtype while storing full history at lower precision.

  A full-attention layer keeps its whole KV history in a low-precision pool, and the first `mixed_precision_first_n` and last `mixed_precision_last_n` tokens of every request at the configured KV dtype in a second pool. The second pool is a native sliding-window + sink layer group, so V2's existing window logic allocates, reuses and evicts it. Attention kernels are unchanged: before each layer the batch is gathered into a staging copy in the KV dtype, attention runs on it, and only the tokens written in this step go back to the two pools. NVFP4 is the first low-precision format.

  Enable with `kv_cache_config.dtype = "mixed_nvfp4_{fp8|float16|bfloat16}"` plus `mixed_precision_first_n` / `mixed_precision_last_n` (default 256); `pool_ratio` optionally splits the KV budget between the two pools. Prototype.
