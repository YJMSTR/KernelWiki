## Dev Engineer Review

- Refreshes SM90 SageAttention with a pre-built, warp-specialized cubin.
- Supports INT8 Q/K with e4m3 PV, head dimension 128, block sizes `(2, 16, 1)`, separate Q/K/V, padding masks, and no KV cache.
- Adds architecture and block-size validation, runtime selection, composite data-type dispatch, and VisualGen configuration support.
- Unifies SM90 and SM100 scale grouping with `SageScalePartition` and `PartitionTraits`.
- Adds Hopper Q/K partition layouts, scale geometry helpers, K-mean smoothing, and V-staging support.
- Removes unsupported SM89 and contiguous-block SM90 variants.
- Updates cubin metadata and size handling for `DATA_TYPE_KV_INT8_E4M3`.
- Propagates `smooth_k` through the VisualGen, PyTorch, nanobind, and C++ attention APIs.
- Removes the standalone FMHA test because SageAttention uses a pre-built cubin.
- Review focus: verify metadata, scale layouts, workspace sizing, pointer routing, unsupported-configuration handling, error handling, API consistency, and performance.
