## Summary

- Replace the legacy flattened MegaMoE sources with the exported architecture-specific kernel package, preserving its directory structure and kernel entry points.
- Integrate Blackwell and Rubin generic/generation kernels behind the existing `MEGAMOE_CUTEDSL` backend, without adding a public backend or configuration field.
- Preserve current MoE lifecycle and typed activation interfaces; update kernel descriptors, workspace handling, tactic validation, deterministic defaults and fallback selection.
- Include the FC1 scheduling synchronization fix, adaptive-bucket warmup, and compatible direct-input/routing paths.
- Apply routing weights before FC2 input quantization for DeepSeek-V4 and after FC2 for other models. Update existing reference and tactic tests without relaxing accuracy tolerances.
- Warm cached CuTe DSL tactics during tuning, including after distributed cache synchronization. Exclude collective MERGE tuning and allow failed warmup attempts to retry.
