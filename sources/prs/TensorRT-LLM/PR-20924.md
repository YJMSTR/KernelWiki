## Description

Helix aggregate chunked prefill must attend to earlier MLA KV records that are stored across context-parallel (CP) ranks. Before this change, a cached context could not reconstruct its full token history from its rank-local persistent cache.

This PR derives each rank's owned read intervals from the existing global history-chunk plan, loads the corresponding compressed KV records, and uses the variable-size CP all-gather to assemble each bounded history chunk. Every rank participates in the same collective sequence, including iterations where it contributes zero records. FP8 cache records are dequantized locally to the query dtype before communication. A CUDA reorder operator restores request and token order, then separates compressed KV from the shared RoPE key segment (`k_pe`) for the existing MLA expansion, attention, and softmax-merge path. Persistent KV remains sharded.
