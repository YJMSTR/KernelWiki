## Optimization
This PR optimizes GVR V2 in five areas:
  - Register path coverage: Extend register-resident routing and adjust CTA sizes and per-thread capacity. **Always select register path when N <= 12K**
  - Initial interval estimation: Add distributed sampling with configurable density while retaining dense sampling for small K.
  - Boundary-bucket refinement: Add argmax, warp-level ranking, and complement selection; adjust the small-bucket threshold.
  - Histogram and output handling: Vectorize shared-memory histogram accesses, stage outputs in shared memory, and specialize static dimensions.
  - Memory scheduling and register usage: Add row prefetching, defer fragment loads, and reload bin-transform parameters to enable recomputation.
