## Dev Engineer Review

DWDP adds an opt-in SM fabric-gather prefetch path. If the gather operator is unavailable or a plan cannot use gather, the weight manager retains copy-engine prefetch. The change also adds TCPStore rendezvous for independently launched workers and preserves the MPI path when store rendezvous is not configured.

KDA replay buffers now use the V2 cache-manager lifecycle and contribute to cache-cost estimates. The changes also cover disaggregation exclusions, suspend/resume state, and context-only warmup and empty-batch behavior. Verify replay-buffer sizing and slot lifecycle for context-only and generation workers.

CuTeDSL adds SM reservation and an SM107 dense-GEMM scheduler override. Routing adds `TLLM_ROUTING_DISABLE_COOP_LAUNCH`. The Kimi K3 example scripts assign each rank a separate DeepGEMM JIT cache directory. The GB300 Kimi K3 configurations change worker environment variables. The executor moves KV-cache-event flushing to rank-symmetric call sites under attention DP.
