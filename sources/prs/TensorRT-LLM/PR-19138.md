## Summary

Two independent QSA indexer optimizations for Qwen3.8-Flash-Next, plus the
accuracy guard that covers both.

### 1. Enable the GVR Top-K for the QSA indexer

QSA drove its Top-K through the exact radix implementation only. This dispatches
the hint-free self-sampling GVR (Guess-Verify-Refine) engine when its
prerequisites hold, behind a new `enable_heuristic_topk` serving knob
(default off).

The predicate that decides this already existed for DSA, so it moves from
`sparse/dsa/params.py` up to the shared `sparse/params.py` and both backends
call it. QSA passes its own opt-in; when the prerequisites are not met it falls
back to the exact radix Top-K with a one-time warning.

Prerequisites: Blackwell (SM100/103), the CUTLASS DSL, a compressed-group budget
(`indexer_budget / indexer_compress_ratio`) in {512, 1024, 2048}, and an
`indexer_compress_ratio` of 4. The GVR kernel itself also accepts ratio 1, but
`QSASparseParams._validate_selection_geometry` rejects anything below 2, so 4 is
the only value QSA can reach.
