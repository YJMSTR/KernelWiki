## Description

### Impact

- **New FMHA library `prims_ts_sparse_mla`** (`PrimsTSSparseMlaFmha`, `tensorrt_llm/_torch/attention/backends/fmha/prims_ts_sparse_mla.py`): DeepSeek-V4 generation-phase sparse MLA on the vendored PrimTS CuTe DSL kernel (`BatchSparseMLADecodePagedTSWrapper`, flashinfer-ai/flashinfer#5434).
- **Default path change, SM100 only.** DeepSeek-V4 Flash / Pro generation attention on B200 / GB200 now runs on PrimTS instead of TRTLLM-Gen (`DEFAULT_FMHA_LIBS` order: `prims_ts_sparse_mla` > `flashinfer_trtllm_gen` > `fallback`). Selection is logged at info level: `FMHA layer N: PrimsTSSparseMlaFmha serves causal requests (...)`.
- **Unchanged:** context phase (TRTLLM-Gen), SM103 / Rubin / all other archs, all other models, `fp8_ds_mla` footer-scale cache and NVFP4 compressed pools (fallback).
- **Opt-out:** `TLLM_FMHA_LIBS=-prims_ts_sparse_mla`.
- **Vendored tree re-pin:** `flashinfer-prims-ts` → yunruis/flashinfer `trtllm-prims-ts-dev-20261023` @ `aa709061` (canonical `trtllm-prims-ts-dev-20261012` @ `0e0761ef` + upstream `main` commits touching `flashinfer/attention/prims_ts`, byte-identical to `main` @ `3bf6d3202`).
