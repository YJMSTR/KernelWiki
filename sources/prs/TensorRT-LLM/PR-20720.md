## Description

VC-Attention for the FLUX.3 Klein pipeline, measured end to end against VANILLA torch SDPA and cuDNN FP8 on B200 and B300. Targets `feat/flux3-image-klein` (#20430) so it lands with the model; the attention backend itself is [#20068](https://github.com/NVIDIA/TensorRT-LLM/pull/20068), vendored here at the same lineage.

1. **VC-Attention recipes on the TRTLLM backend.** `vc_attention: true` selects the recipe, `qk_dtype` picks the variant (`bf16` = VC-Attention-QK16, `fp8` = VC-Attention-QK8) and `vc_repair_budget` sets the fraction of tokens with the largest quantization error that attention recomputes at full precision (0 keeps the tile means). The recipe fixes its own block sizes, so `q_block_size`, `k_block_size` and `v_block_size` must stay 0; the VC rows of the recipe table carry `(0, 0, 0)` like every other table. Needs `TLLM_FMHA_LIBS=+prims_ts`.

   ```yaml
   attention_config:
     backend: TRTLLM
     quant_attention_config:
       qk_dtype: fp8
       v_dtype: fp8
       vc_attention: true
       vc_repair_budget: 0.005
   ```
