## Description

Add DeepSeek-V4.1 inference support to the PyTorch backend for:

- [DeepSeek-V4.1-Flash](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash)
- [DeepSeek-V4.1-Flash-NVFP4](https://huggingface.co/nvidia/DeepSeek-V4.1-Flash-NVFP4)

The implementation includes CSA2 sparse attention, Engram, mHC, model-specific checkpoint loading, tokenizer/tool parsing, and registration of text-decoder and conditional-generation architectures.

## Key Features

- **Encoder and decoder bounded replay:** optional encoder-state recovery retains reusable GLOBAL prefixes; bounded decoder replay preserves complete GLOBAL/index KV while restricting decoder prefill to a prompt suffix. The decoder path is approximate, enabled by default, and can be disabled for full decoder prefill.
- **DSpark speculative decoding:** supports the embedded draft model, captured target states, and acceptance-length tracking.
