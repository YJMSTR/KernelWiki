## Description

Ports the dynamic-kernel-generator (DKG) work on the paged MQA logits kernels onto TRT-LLM's CuTe DSL copies (`fp{4,8}_paged_mqa_logits.py`), one DKG commit per TRT-LLM commit, and makes the CuTe DSL kernel the DSA indexer's default on SM100-family GPUs.

Why stepwise rather than a file swap: the DKG files never finish MLIR emission on the pinned `nvidia-cutlass-dsl==4.8.0.dev0` (9 of 9 configurations hit their 600–1200 s timeout, one left running 86 min, against 1.3 s for this file) → bisected to DKG `3f632717`, the 4-wide vector epilogue that drops `pack_f16x2`/`max_f16x2`/`fma_f16x2` for compiler conversion fusion → grafting only those 4 epilogue sites onto this file reproduces it (1.3 s → >900 s). That commit is skipped, and with it `use_two_level_task_loop` / `use_paired_pipeline_polls`, which restructure the same loop. DKG's import commit is still byte-close to this file (FP8 differs by 20 lines), so each later commit applies 60–90 % of its hunks cleanly.

| Commit | DKG source | What it brings |
|---|---|---|
| Use the FADD2 relu identity | `de741385`, `cb6497a9` | `relu(x) = (x + \|x\|) / 2`, behind a knob |
| next_n atom split, FP8 | `a2dafe8a` | in-kernel
<!-- upstream-excerpt-end -->
