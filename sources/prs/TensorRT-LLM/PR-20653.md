## Description

Replace the legacy optimized Kimi K3 KDA prefill chain with FlashInfer BT16/Small-BH kernels and fused CuTe DSL convolution/input preparation. Prefill reads and updates resident recurrent-state pools directly, avoiding BF16-to-FP32 state staging and writeback while preserving continuation, replay-cache updates, and decode/verification behavior.

- Vendor the two FlashInfer kernels at commit `b8e81a7dae6c2aa5c9aa19c06e81e9a729271493` through the existing source-lock, compatibility-patch, and digest-check workflow. Remove the replaced prefill kernels.
- Fuse short convolution, layout conversion, and input preparation; perform Q/K normalization inside FlashInfer and retain packed BF16/FP8 projection inputs.
- Select Small-BH for eligible small batch/head workloads and BT16 otherwise. Reuse BT16 scheduling metadata across layers and cache fused-convolution specializations without retaining caller buffers.
- Preserve low-rank gate projections, the current core-output contract, aligned generation indices, and replay-copy support.
