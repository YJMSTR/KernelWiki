## Motivation

Speed up DiffusionGemma's BF16 denoising on Blackwell by using FA4 and capturing repeated input preparation and context encoding in CUDA graphs.

## Modifications

- Add FA4 paths for D256 sliding-window and D512 global attention, reusing Triton's paged-KV metadata and cache writes. Support strided Q/K/V inputs and fixed-window graph variants.
- Capture self-conditioning input preparation and subsequent 256-token context passes. Cache temperature schedules on GPU and reuse request-level RNG state and buffers.
- Fuse QKV normalization with RoPE, share RMSNorm reduction across three outputs, and add B300 up/down MoE configurations.
- Fuse logits conversion with softcap and sampling division with the existing two-stage argmax.
- Reuse BBuf's chunked vocabulary statistics from #42099, retaining FP32 sampling probabilities and writing the BF16 self-conditioning copy in the same pass.

## Accuracy Tests

The earlier FA4-enabled 12-request ablation improved throughput from **413.50 to 548.05 tok/s (+32.5%)**, with identical output IDs and denoising step counts. Existing CPU, attention, RNG and CUDA graph regression checks passed on the recorded snapshots.
