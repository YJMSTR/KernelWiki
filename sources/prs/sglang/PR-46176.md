## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
Small per-step DSpark decode costs on DeepSeek-V4.1, each removed without changing any output bit.

- **hc stream mean**: `mhc_stream_mean`, a Triton kernel that averages the four hc streams in torch's order (in-order fp32 sum onto +0); used for the DSpark captures and the replay tail. Unverified shapes and dtypes fall back to `x.mean(dim=1)`.
- **aux packing**: V4 collects the captures in `AuxHiddenStatePacker`, and the mean writes straight into its slot, so the logits processor no longer `torch.cat`s them.
- **markov draft step**: when one rank holds the whole unpadded vocabulary (TP1, or DP attention with `--enable-dp-lm-head`), skip the identity vocab gather so the draft step runs one pass instead of two.
- **draft wo_a**: on Blackwell, target-verify calls outside the TP4 fast path (more rows, other group counts, as in the DSpark draft) use the existing strided bmm instead of `einsum` + transpose copy.

Without DSpark nothing changes.
