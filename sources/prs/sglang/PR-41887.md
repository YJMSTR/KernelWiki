## Motivation

Adds a Blackwell CuTe DSL dual-GEMM kernel that fuses:

gate = input @ gate_weight
up = input @ up_weight
output = SiLU(gate) * up

Tested on B200
- Llama 3 8B FP8, BS1, **5.2% Offline Gains**
- Qwen 2 7B FP8, BS1, **7.8% Offline Gains**
