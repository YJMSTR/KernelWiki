## Motivation

Reduce synchronization and kernel overhead in GLM-5.3-Flash DFlash decoding. The DFlash/KDA-only comparison improves average decode throughput from **1091.85 to 1199.72 tokens/s (+9.88%)** on 8×B300, with essentially unchanged memory usage.

## Modifications

- Reuse CPU-side sequence lengths to avoid blocking GPU-to-CPU copies during DFlash input preparation.
- Build pooled page tables once per verification batch and reuse them across sparse attention layers.
- Tune KDA recurrence and gated norm launch configurations on SM103 while preserving the tested rounding behavior.
- Extend the sigmoid RMSNorm BT8 dispatch to BF16, D=128 workloads with 8–256 rows.

The FP8 MoE weight-layout optimization has been split out of this PR.

## Accuracy Tests

Paired service checks matched output tokens and speculative acceptance statistics. Real-rejection cases also matched the checked generated-token logprobs.

Kernel checks cover KDA output/state parity and output/rstd parity for nearby norm shapes. Regression checks cover pooled metadata CUDA Graph replay and sequence-length bounds.
