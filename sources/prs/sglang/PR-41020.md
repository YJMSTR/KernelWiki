## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
> This PR was "stack 3/4" of the DeepSeek-V4.1 AMD series (#41018 to #41021). It now follows the CUDA dsv4.1 layout (#39646, #39652, #39653, #39656, #39664, then #38798): kernel PRs by domain, each on `main` with no callers, then one integration PR. This is the third kernel PR; it does not depend on #41018 or #41019.

## Summary
- `ops/attention/sparse_decode_reduce_hip.py`: `gfx_sparse_split_reduce` combines the split-KV partials of aiter's gfx950 `pa_decode_sparse(..., skip_reduce=True)`, bitwise equal to aiter's own reduce, with the attention sink and an optional inverse RoPE of each head's tail.
- `ops/attention/dsv4/compact_attention_hip.py`: sparse decode attention that reads the compact V4.1 pages (528 B fp8 + ue8m0, 288 B e2m1 + e4m3) directly through aiter's gfx950 `_qkpv_fp8`, with main and extra slot ranges and 16-head groups.
- `ops/attention/dsv4/swapab_gluon_hip.py`: the 16-head swap-AB Gluon kernel for HIP, argument-compatible with the SM100 kernel (CDNA4 MFMA, bf16 hi + lo compensated PV). It reuses the SM100 module's `_load_v4`, which is plain Gluon; `swapab_attention` gains `inv_rope=None`.
- `ops/attention/dsv4/attn_glue_hip.py`: single-launch Triton replacements
<!-- upstream-excerpt-end -->
