## Motivation

FlashMLA's 2026.09.30 V4.1 kernels read a token-interleaved KV cache and are faster at decode. They ship in the `sgl-flash-mla` wheel (release workflow #45651), which also carries every pre-release kernel sglang uses behind `use_legacy=True`. This moves all CUDA FlashMLA calls to that wheel and adds the interleaved layout as an opt-in, so existing deployments are unchanged.

Supersedes the serving side of #45635 (co-authored), keeping the block-split `v41` layout so gfx950 / aiter_sparse keeps working.

- New `SGLANG_DSV4_KV_LAYOUT=v41_new` (`KVLayout.V41_NEW` / `V41_FP4_NEW`): the V4.1 bytes interleaved per token, unpadded. `v41` keeps the block-split layout.
