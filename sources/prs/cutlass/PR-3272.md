## Upstream PR description (verbatim excerpt)

<!-- upstream-excerpt-start -->
This PR adds two CuTeDSL Blackwell GeForce block-scaled dense GEMM examples:

  - `dense_blockscaled_gemm_persistent_cooperative.py`
  - `dense_blockscaled_gemm_persistent_pingpong.py`

  The examples support persistent scheduling with cooperative and ping-pong warp-group schedules, and add shared dispatch support for SM120 block-scaled MMA variants.

  Supported A/B datatype modes:

  | Mode | A/B dtype | Scale dtype | SF vec size | Supported tile shapes |
  | --- | --- | --- | --- | --- |
  | NVFP4 | E2M1 x E2M1 | E4M3 | 16 | 128x128x128, 128x128x256 |
  | MXFP4 | E2M1 x E2M1 | E8M0 | 32 | 128x128x128, 128x128x256 |
  | MXFP8 | E4M3 x E4M3 | E8M0 | 32 | 128x128x128 |
  | Mixed FP4 x FP8 | E2M1 x E4M3 / E4M3 x E2M1 | E8M0 | 32 | 128x128x128 |

  Measured on RTX PRO 6000 Blackwell Server Edition with M=N=K=8192, warmup=50, iterations=100:

  | Mode | Best TFLOPS |
  | --- | ---: |
  | NVFP4 | ~1629 TFLOPS |
  | MXFP4 | ~1615 TFLOPS |
  | MXFP8 | ~802 TFLOPS |
  | Mixed FP4 x FP8 | ~806 TFLOPS |
<!-- upstream-excerpt-end -->
