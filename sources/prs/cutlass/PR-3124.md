## Summary
Adds an **SM103 (B300/GB300) grouped block-scaled GEMM** kernel for CuTeDSL — a persistent kernel that dispatches multiple independent block-scaled GEMMs with different M/N/K shapes in a single launch. It fuses the **SM103 dense block-scaled kernel internals** with **SM100-style grouped scheduling**, filling the gap where upstream has SM100 grouped and SM103 dense but no SM103 grouped kernel.

Rebased onto the current (v4.5) tree, which reorganized the CuTeDSL examples and changed the TMEM-storage API since this PR was first opened.

## Files
- `examples/python/CuTeDSL/cute/blackwell/kernel/blockscaled_grouped_gemm/sm103_grouped_blockscaled_gemm.py` — `Sm103GroupedBlockScaledGemmKernel` + `run()`.
- `test/examples/CuTeDSL/sm_103/test_grouped_blockscaled_gemm.py`, `test/examples/CuTeDSL/sm_103/conftest.py` — pytest suite.

## Key design
- SM103 internals: 7-warp layout with a **dedicated scale-factor TMA warp** (warp 6) separate from the A/B TMA warp (warp 5), MXF4/NVF4 ops, hand-unrolled MMA mainloop.
- SM100 grouped scheduling: `StaticPersistentGroupTileScheduler`, per-group tensormap updates via shared memory.
