## Summary

- Add a Hopper persistent FP8 GEMM example with per-tensor scaling and a compile-time elementwise `epilogue_op`.
- Provide high-accuracy erf-GELU and a clipped degree-11 polynomial GELU approximation from one shared kernel skeleton.
- Add Hopper pytest coverage for both epilogues at two target problem sizes with BF16 output and non-unit scales.

## Motivation

Fusing GELU into the persistent GEMM epilogue avoids materializing the unfused GEMM result and launching a separate activation kernel. Compile-time epilogue specialization supports different elementwise operations without a runtime branch or duplicate GEMM implementations.

## Implementation

- The kernel is derived from `dense_gemm_persistent.py` and retains its mainloop, multicast, K-block, and persistent scheduling behavior.
- `epilogue_op` is passed as a `cutlass.Constexpr` and specialized by `cute.compile`.
- The `erf_gelu` path evaluates `0.5 * x * (1 + erf(x / sqrt(2)))` in FP32.
- The `poly11_gelu` path evaluates a clipped odd degree-11 approximation of the standard-normal CDF in Horner order, then forms `x * CDF(x)` in FP32.
